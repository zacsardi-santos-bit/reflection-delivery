I want to add an optional combining function parameter so different kinds of aggregation can be expressed by whoever's calling it. On top of that, there's no general-purpose flat-reduction helper in that module and I want one added. It should take a list of distributed futures plus a plain combining function and return a computable result that yields the combined value when executed, useful when I've got a bunch of worker tasks already running and just want to fold their results together with something simple like summing them.

Both the updated tree reduction and the new flat reduction need to work correctly across different partition counts, including the single-partition edge case. btw make sure the tree helper still behaves when given the lazy computations it already handled, don't regress that path while wiring in the futures support and the new combining-function argument.
