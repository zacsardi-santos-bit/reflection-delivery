I want three things wired into the graph's event handler setup (the function that registers handlers by event name plus callback). Third, on edge click, animate the graph to bring the "other" endpoint into view: if the source node is currently selected focus the target, if the target is selected focus the source, and if nothing's selected just default to focusing the target node. Oh and to support all this the context object passed into that handler setup function needs two new fields, one for updating the edge tooltip state and one for a canvas reference.
