I'm working on the Azure Synapse Pipeline integration in Apache Airflow over in the providers code, and right now there's only a synchronous hook, which means it can't be used with deferrable operators or anything running in an async execution context. I want an async-capable variant living alongside the existing sync hook so I can build non-blocking integrations, because otherwise any operator waiting on a Synapse pipeline to finish has to block a worker thread instead of deferring and resuming when the run completes.

The async hook needs to handle both auth methods, one using a client ID, client secret, and tenant ID, and the other using the default Azure credential with optional managed identity and workload identity settings. Oh and if someone passes client secret creds but forgets the tenant ID, I want it to raise a clear error that actually mentions the tenant ID is required, not some vague failure.

Beyond auth, it should expose a way to grab the current status of a running pipeline run as a string, support refreshing its underlying connection, and cleanly close that connection when done. After closing, the internal connection reference should be set back to null (None). Also it should work as an async context manager so the connection gets cleaned up automatically when the block exits. That's basically the whole surface I need.
