I'm hitting a display bug in the Task Instances list view in the Airflow web UI. The DAG ID, Task ID, and Run ID columns are showing raw HTML markup as literal text instead of rendering as clickable links, so you see the actual tags and markup characters as plain text rather than navigable hyperlinks that take you to the right DAG, task, or run page. Basic navigation is broken because none of those cells are clickable.

I dug into it and it looks like the template engine is escaping the output from the link-builder utilities instead of rendering it. That's actually the correct default (escaping unknown strings is the safe thing to do), but the problem is those three helper functions, the ones that build the task instance link, the DAG link, and the DAG run link, all return plain strings. Since a plain string reads as untrusted, the engine escapes it again and the HTML tags leak out as visible text.

What I want is for those three link-building functions to wrap their HTML in a safe markup type (a trusted, pre-escaped HTML type) so the template engine treats the output as already-rendered HTML and doesn't re-escape it. One thing to be careful about: special characters in the IDs still need to stay URL-encoded in the generated hrefs so we don't open up any injection, they just shouldn't show up as literal text in the rendered links anymore. So the encoding behavior stays, only the return type changes to signal the content is trusted.
