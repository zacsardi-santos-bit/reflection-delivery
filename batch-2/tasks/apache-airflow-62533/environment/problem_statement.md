## Description

The Task Instances list view in the web interface is displaying raw HTML text in the DAG ID, Task ID, and Run ID columns instead of rendering them as clickable links. Users see literal markup characters and tags as plain text rather than navigable hyperlinks.

## Expected Behavior

- The DAG ID, Task ID, and Run ID columns in the Task Instances list view should display as clickable links that navigate to the appropriate pages.
- The HTML generated by the link-building utilities should be rendered by the template engine rather than escaped.
- Special characters in IDs must remain URL-encoded in the generated links to prevent injection, but must not appear as literal text in the rendered output.

## Root Cause

The utility functions that produce HTML links for DAG IDs, task IDs, and run IDs return plain strings. The template engine treats plain strings as unsafe and escapes them — which is the correct default behavior — but it means the HTML tags end up as visible text instead of rendered markup. These functions need to return their output as a trusted, pre-escaped HTML type so the template engine renders them correctly instead of escaping them again.

## Why This Matters

Users navigating the Task Instances list view cannot click through to individual DAGs, tasks, or runs because those cells show raw HTML instead of rendered links. This breaks basic navigation in the UI.
