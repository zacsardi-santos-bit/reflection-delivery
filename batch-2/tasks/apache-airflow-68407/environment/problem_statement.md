I'm building out an AI agent operator in Airflow and I want to add a "code mode" so the model can write one block of code that calls all the tools it needs (loops, conditionals, parallel calls) in a single turn instead of doing a separate model round-trip per tool call. For orchestration-heavy workflows that hit 10 tools this is a huge latency and token win, one turn vs ten.

So I want a new boolean param on the operator, defaulting to off, and when it's off behavior is totally unchanged, no new fields injected into agent creation. When it's on, a code-execution capability gets built and appended to the end of the agent's capability list at execution time, not at construction time, so the operator stays serialization-safe. If the caller already passed their own capabilities through the existing agent params, keep those and just tack the code-mode one on at the end.

Couple guard rails. First, if someone turns on both code mode and durable/replay mode I need to reject that at construction time with a clear error, since durable replay needs a stable step order that code mode can't guarantee. Second, the harness package powering code mode is an optional dependency, so if that specific package isn't installed, calling the capability builder should raise an optional-provider-feature error referencing the feature name. But if the package is present and it's a transitive dependency inside it that's broken, re-raise that original import error as-is, don't mask real breakage behind a misleading "go install the extra" message.

Also I need to update both toolset implementations, the hook-based one and the SQL-based one, so their tool definitions declare a string return type, which lets the code execution environment render properly typed function signatures. The return schema field only exists in newer versions of the AI library though, so I want a shared compat utility module with a boolean flag checked at import time plus a helper function that returns the right keyword argument when the feature's supported, or an empty dict when it isn't.
