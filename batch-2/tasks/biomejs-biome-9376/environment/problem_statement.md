I want to add a new nursery lint rule to Biome that flags duplicate titles across test cases and test group blocks that live in the same scope. The motivation is real: when a file grows it's easy to accidentally give two different tests or two different describe-style grouping blocks the exact same title, and then when something fails you can't tell which one actually broke just from the output. Other JS testing lint plugins already catch this and Biome doesn't have an equivalent yet, so this also helps folks migrating over.

Here's the behavior I'm after. If two individual test cases share the exact same name inside the same grouping block (or at the top level), flag it as a duplicate. Same deal for two grouping blocks with the same name at the same level. The warning should say clearly what kind of duplicate it found (a test vs a grouping block) and tell the dev a duplicate title already exists in the same scope and that they should rename it.

It's gotta be scope-aware, so a title reused inside a different nested grouping block is totally fine and shouldn't fire, since those are different scopes. Also tests and grouping blocks are checked independently, so a test and a grouping block sharing a name is allowed, don't flag that.

For comparison, only static string titles count. Template strings with dynamic interpolations can't be reliably compared at analysis time, so skip those and don't flag them. It lands as a new rule in the nursery group under `@crates/biome_js_analyze/src/lint/nursery/` with the usual registration wiring, so make sure it's hooked up there too.
