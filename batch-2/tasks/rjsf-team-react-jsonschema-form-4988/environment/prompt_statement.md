I'm building out a form library where the form shape comes from JSON Schema, and I keep hitting this annoying thing where users leave optional nested sections totally blank and the submitted data still carries these hollow empty objects around, fields that are blank or unset, and the APIs downstream really don't want that, they'd rather get nothing than a bag of empty containers. So I want a utility function that takes the form data plus its schema and strips out any optional properties whose values are empty. By empty I mean empty strings, absent or unset values, empty arrays, or objects that recursively bottom out to only empty stuff. It's gotta work all the way down through deeply nested structures, recursively. Anything the schema marks as required should never get removed even if it's empty. Arrays of objects need handling too, process each element individually using whatever schema applies at that position. And it's not just nested objects, scalar optional fields with empty string values should get cleaned up as well. Couple subtleties to watch: boolean false and the number zero are real values, don't treat those as empty, keep them. Also if a property shows up in the data but there's no matching schema entry for it, just leave it alone, don't touch it. Oh and if after all the pruning the whole result object ends up empty, return nothing rather than handing back an empty object. This is really about making sure only data with actual content flows through, so submission is cleaner for the consuming systems.
