I'm doing some work on the plugins popup in our terminal UI and right now it's kind of a mess, it just dumps every plugin from every marketplace source into one flat list with no filtering, so if you've got a bunch installed across a few sources you're stuck scrolling through everything to find what you actually care about. I want to add a real tabbed interface to that popup, navigable with left and right arrow keys, that lets people jump between different views. At minimum there should be an "All Plugins" tab showing everything from all sources, an "Installed" tab that shows only currently installed plugins with a header reading "Installed plugins." plus a count line like "Showing N installed plugins.", and a dedicated tab for the official curated marketplace that only shows plugins from that source, and on that tab the marketplace source label should be dropped from the individual plugin rows since it's obviously redundant there. Then any additional marketplace sources each get their own tab too.

Couple of important behaviors: when someone switches to a different tab, whatever search query they'd typed needs to get cleared automatically so they start fresh on the new tab. Also if two or more marketplace sources happen to share the same display name, their tabs have to be visually distinguished with a numbered suffix, something like "Marketplace Name (1/2)" and "Marketplace Name (2/2)" so you can tell them apart, and the identity of each marketplace tab needs to be keyed off its filesystem path rather than just the name so duplicate-named ones stay individually addressable. Oh and the big one, the currently active tab should be tracked by a stable string identifier, so when the plugin data refreshes in the background the user stays on whatever tab they were looking at instead of getting yanked back to the first one. This whole thing is really about discoverability, letting folks stay focused on the subset that's relevant to them at any moment.
