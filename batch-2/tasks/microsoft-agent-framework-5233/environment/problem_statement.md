I'm building AI agents that chew through complex, multi-step tasks, and I keep hitting the same wall: there's no built-in way for an agent to track its own work items across a session. I want it to break a big request into smaller pieces, mark stuff done as it goes, and remember what's still outstanding across multiple turns of the same conversation. Right now every developer reinvents this task-tracking logic from scratch, which is silly.

So I'd like a reusable AI context provider that automatically hands agents the tools to manage a todo list. It needs tools to add new items (each with a title and an optional description), mark an item complete by its ID, remove an item by its ID, retrieve just the remaining incomplete items, and retrieve all items. Each new item should get a unique auto-incrementing numeric ID starting at 1. And the state has to persist across multiple agent invocations within the same session, so if the agent adds a task one turn it can still see it the next turn.

Also, and this is important for my host app, I want the provider to expose public methods so my own code can read the full list of items or just the incomplete ones directly from a given session, without routing through the AI tools, handy for showing progress to the user. Oh and calling those methods on a brand-new session that's never had any todos should just return an empty list, no errors, no fuss.
