I want to make plan mode available by default instead of hiding it behind an experimental opt-in. Right now if someone tries to use plan mode through the command-line flag, it just gets silently ignored unless they've already flipped on the experimental setting first, which is super confusing and means basically nobody discovers the feature. It's a genuinely useful thing for safely exploring and designing a solution before touching any code, so hiding it reduces discoverability and stops people benefiting from it out of the box.

So the change I'm after is treating plan mode as a regular enabled-by-default feature rather than experimental. The config setting that controls it should default to on now (still let people opt out if they want), and its description needs updating so it reads like a stable opt-out feature and not an experimental opt-in toggle. Also the list of selectable approval modes should include plan mode as a first-class option alongside the others, so when the plan approval mode gets picked via the command line it takes effect immediately without any experimental gating getting in the way. And anywhere in the code that gates plan mode behavior behind an "is plan enabled" style check, that needs to respect the new default too. Basically no configuration required to use it.
