I want Streamlit to nudge people toward the official agent skills when they haven't installed them yet. The idea is when someone runs an app interactively, the terminal prints a short recommendation telling them these skills help AI coding assistants build and debug Streamlit apps better, and honestly most devs have no clue they even exist. The message should include the line "Help agents write better Streamlit apps?", reference the `streamlit skills` command, and say "Install the official Streamlit skills" so they know exactly what to run.

Some suppression rules though. If the skills are already installed (found in any project-local or global agent directory) don't print anything. In headless mode, so cloud deployments or CI pipelines, it should never show up. And when the terminal welcome message is turned off via config, skip the message and don't even bother running the install check, we shouldn't waste a filesystem lookup there.

To make this work I also need a new public function that reliably detects whether the bundled skill is currently present anywhere on the system. It should check both project-local and global agent skills directories and return true if it finds the skill as a directory or symlink in any of them. Oh and it's gotta be resilient to filesystem errors, so if resolving one category of directories throws, still check the others, and if every lookup fails just return false rather than raising an exception.
