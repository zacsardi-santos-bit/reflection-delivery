I'm working on a grammar linter and I want to add a new module for phrase corrections that groups related corrections together. Right now, correcting something like "have went" to "have gone" requires a separate rule for each auxiliary verb form — one rule for "have went", another for "had went", another for "having went", and so on. The same problem applies to many other correction categories. I'd like a dedicated module where multiple variant forms of the same error can be handled as a single grouped rule.

The new module should cover a broad set of common writing errors, including: confusing "adieu" (farewell) with "ado" (fuss) in phrases like "further adieu" or "much adieu"; using "client's side" or "server's side" instead of the hyphenated compound adjective forms; writing "definitive article" instead of "definite article"; confusing "explanation mark" with "exclamation mark"; all conjugated forms of "have went" (and "had went", "having went", "has went") which should each become the correct form with "gone"; the same pattern for past/passed confusion; "hone in on" variants which should become "home in on"; "invest into" variants which should use "in"; various "worse/worst" confusions across many phrases; "how it looks like" which should offer two alternatives (either remove "like" or replace "how" with "what"); and other common idiom errors.

Some of these corrections should offer multiple valid alternatives as separate suggestions — for instance, "a whole entire" should suggest both "a whole" and "an entire" as options. The corrected text should match the capitalization style of the original.
