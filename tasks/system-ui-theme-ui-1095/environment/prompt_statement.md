I'm working with the color modes package and I've noticed that the utility responsible for converting theme objects into CSS custom properties doesn't handle the case where the theme data is undefined. If I call it without providing a valid theme object — for example, when a particular theme section simply isn't defined — it fails instead of returning an empty result. It would be great if the utility could gracefully return an empty object when given undefined input, rather than crashing. This would make the system much more robust when theme data is only partially available.
