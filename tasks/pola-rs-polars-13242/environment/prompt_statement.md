I'm working with the Polars dataframe library's SQL interface and running into an issue with multi-column joins. When I try to join two tables on more than one column at a time — using AND to combine multiple equality conditions in the ON clause — the query fails. It seems only single-condition equi-joins are currently supported, which is really limiting for real-world data that uses composite keys.

I'd like the SQL engine to support join conditions that combine multiple equality comparisons with AND, for both inner and left joins. The matched columns don't always have the same name on each side, so cross-column matching should work too. I also need this to work when chaining several joins together in one query, and when such joins are used inside subqueries. Malformed conditions — like column references that aren't fully table-qualified or expressions that aren't equality comparisons — should still be rejected as errors.
