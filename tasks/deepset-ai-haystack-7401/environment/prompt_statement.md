I'm working on adding an LLM-based evaluator to Haystack that lets developers assess the quality of pipeline outputs using a language model as the judge. The idea is that a developer specifies their evaluation criteria in plain language, declares what inputs the evaluator should receive and what scores it should produce, and gives a few examples to guide the model's judgments. The evaluator then calls the underlying LLM, parses the structured response, and returns consistent results.

I need this evaluator to be a proper Haystack component — serializable, deserializable, and importable from the main evaluators package. It should validate its configuration thoroughly at initialization (rejecting malformed inputs, outputs, or examples with helpful errors), validate at runtime that all provided input lists are the same length, and produce a results list where each item is a dictionary of evaluation scores plus an identifying label. The component should also expose a method for generating the prompt template it uses, and separate methods for validating its input parameters and output structure so those checks can be used independently.
