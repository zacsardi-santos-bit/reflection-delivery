## Description

We need a new page in the app to display supplemental conditions of sale for auctions. Right now there's no dedicated place for users to browse these legal agreements, and there's no way to view an individual agreement's details. This feature should make it easy to see which auctions currently have active conditions of sale, and also allow browsing past agreements organized by auction type.

## Expected Behavior

- A main page lists all sale agreements, defaulting to a "Current" tab showing active auction agreements.
- A "Past" tab lets users browse historical agreements, organized into labeled categories by auction type:
  - Benefit auctions appear under one heading
  - Commercial partner auctions appear under a separate heading
  - Artsy-run auctions appear under their own heading
- Category headings should only appear when there are agreements to show — empty categories should be hidden entirely.
- Each agreement entry shows the auction name and its date range.
- Individual sale agreements are viewable on a detail page that also shows the auction name and associated date range.

## Why This Matters

Buyers need to be able to find and read the supplemental conditions of sale for any auction they're participating in. Without this page, those documents are inaccessible through the main app interface. Grouping past agreements by auction type makes it easier to navigate a potentially large list.
