I'm working on adding support for the native Windows SSH agent to posh-git. On Windows 10 and later, there's a built-in SSH service that ships with the operating system, but posh-git currently doesn't know about it at all. I'd like to add functions that can detect whether this native service is available, and if so, start it up and configure things properly.

Specifically, I need a function that checks whether the native Windows SSH agent service is present and returns the service object if it is. I also need a function that orchestrates the full startup process: if the service is disabled and the user is an administrator, it should enable and then start the service; if the service is disabled but the user is not an admin, it should write an informative error message and exit gracefully without trying to start the service. When the service is just stopped (not disabled), it should start it normally.

Beyond starting the service, the startup function should also configure git to use the correct SSH executable path — but only if that setting hasn't already been configured. It should also handle SSH key loading intelligently: check whether any keys are already loaded, and only add keys if the agent is empty. This avoids unnecessary prompts that can occur with the native agent when keys have already been added.
