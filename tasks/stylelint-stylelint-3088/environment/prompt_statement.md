I'm working on a CSS linter and I'd like to add support for restricting which types of selector relationships are used in a stylesheet. Specifically, I want two new lint rules: one that lets you specify a list of selector relationship types that are forbidden (and flags any use of those), and another that lets you specify a list of selector relationship types that are the only ones allowed (and flags anything outside that list).

Both rules need to handle the fact that the descendant relationship can be written with a space, a tab, or a newline — all of these should be treated as equivalent when checking against the configured list. Both rules should also correctly handle combinators that appear inside pseudo-class selectors, not just at the top level. There's also a non-standard reference combinator syntax (where a word is wrapped in forward slashes) that should be ignored by both rules rather than triggering violations.

To support these rules, I also need a utility function that can determine whether a combinator node from the selector parser represents standard CSS syntax or not — specifically, returning false for reference combinators and true for all standard ones.
