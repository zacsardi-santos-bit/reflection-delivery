I'm working with the Dapr workflow engine and I've noticed that child workflows (sub-orchestrations) don't work correctly. When I set up a parent workflow that calls a child workflow — passing the parent's input to the child, awaiting the child's completion, and returning the child's output — the execution never completes successfully. The parent just hangs or fails instead of getting the child's result back.

This pattern is really common for composing complex workflows out of smaller, reusable pieces. For example, a root workflow that receives some input should be able to hand that input off to a child workflow, wait for the child to finish, and then return whatever the child produced. Right now that doesn't work in the actor-based backend. I'd expect this to work seamlessly, including when the input contains non-ASCII characters like Unicode text.
