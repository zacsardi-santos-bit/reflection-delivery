For vSphere configurations that include multiple named virtual center entries, the logic must handle the per-entry password independently—restoring the password for any virtual center that was carried forward from the existing config without a new password, while leaving new or explicitly-updated virtual centers unchanged. The implementation should only touch password-type fields and must not interfere with changes to any other configuration fields.
