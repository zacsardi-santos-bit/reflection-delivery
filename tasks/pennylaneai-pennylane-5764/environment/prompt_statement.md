I'm working with the quantum chemistry module and I need a convenient, unified way to compute the molecular dipole moment operator for a given molecule. Right now, calculating the dipole observable requires knowing which backend-specific helper to call and piecing together the workflow manually — there's no single high-level entry point that handles both the built-in differentiable backend and the external plugin backend through the same interface.

I also need access to the parity transformation as a fermion-to-qubit mapping option. Currently, only two mappings are available in the relevant utility, and the parity mapping is missing entirely — both from the function itself and from its error message when an unsupported mapping is passed.

I'd like a new function added to the quantum chemistry module that accepts a molecule object and optional parameters for choosing the backend, the fermion-to-qubit mapping (including parity), an active space, custom wire labels, and differentiable geometric arguments. The function should raise informative errors for unsupported backends, unsupported mappings, and open-shell molecules.
