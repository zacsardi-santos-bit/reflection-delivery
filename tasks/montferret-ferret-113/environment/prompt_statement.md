I'm working on adding a new built-in function to the ferret query language's objects standard library. The function should combine two arrays into an object — the first array holds string field names and the second holds the corresponding values. I want it to behave the same way that ArangoDB handles this operation.

The function should validate that exactly two arguments are provided, that both are arrays, and that every element in the keys array is a string. If the two arrays have different lengths it should return an error. When successful, it should return an object mapping each key to the value at the same position. One important edge case: if the same key appears more than once in the keys array, only the first occurrence should be kept along with its value — subsequent duplicates should be silently dropped.
