I'm building a host application that embeds WebAssembly using the Wasmer C API. I can already compile and instantiate modules, and I can inspect what a module exports — but I have no way to inspect what a module *imports* before I instantiate it. I need to be able to query the list of imports from a compiled module, find out how many there are, retrieve each one by index, and for each import discover its kind (function, memory, table, or global), its name, and the module/namespace it belongs to.
