I'm working with a Rust template engine and I'd like to add support for line-oriented template syntax. Right now, the syntax configuration builder only allows customizing the bracket-based delimiters for blocks, variables, and comments. I'd like to also be able to configure a "line statement prefix" so that any line starting with a given string is treated as a block statement (without needing opening and closing bracket delimiters), and a "line comment prefix" so that any occurrence of that string on a line removes everything from there to the end of the line.

For example, if I configure a hash character as the line statement prefix, a line beginning with that character should produce the same block tokens as a standard block delimiter pair would, and if I configure a double-hash string as the line comment prefix, any occurrence of that string on a line should strip the rest of that line. The feature should require the existing custom syntax feature flag to be enabled, just like the existing delimiter customization.

A few important edge cases: if the prefix appears after other non-whitespace content on a line it should not be treated as a line statement. Line statements should also support multi-line expressions when there are open brackets or parentheses. Both the line statement prefix and the line comment prefix should be configurable at the same time, and they should work together in the same template.
