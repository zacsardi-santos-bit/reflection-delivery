I'm working on adding Azure Blob Storage support to SkyPilot's storage system. One thing I noticed is that the system already validates bucket names for AWS S3 and Google Cloud Storage — if you give it an invalid name it raises an error right away with a useful message. But for Azure, there's no equivalent validation, so you just get a confusing cloud-side error when the name doesn't meet Azure's container naming rules.

I'd like the same kind of early validation for Azure containers. Azure has specific naming requirements: names must be between 3 and 63 characters, must consist only of lowercase letters, digits, and hyphens, must start and end with a letter or digit, and cannot contain two consecutive hyphens. When a name violates any of these rules, a storage name error should be raised with a descriptive message, consistent with how invalid S3 and GCS bucket names are handled today.
