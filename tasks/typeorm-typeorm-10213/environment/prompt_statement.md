I'm working with a query builder and running into an issue with WHERE clause operator precedence. When I chain multiple conditions using AND and OR logic, the generated SQL doesn't automatically group each condition in parentheses. This can cause subtle bugs — for example, if I add an OR-based search alongside a strict equality filter, the database might evaluate them in the wrong order because there are no brackets separating the individual conditions.

I'd like to have a data source-level configuration option that, when enabled, automatically wraps each WHERE clause condition in parentheses. This way, combining conditions like a simple equality check with an OR-based condition would reliably produce SQL where the OR conditions are properly isolated with brackets, ensuring correct boolean logic evaluation. The option should work globally so I don't have to add parentheses manually to every query.
