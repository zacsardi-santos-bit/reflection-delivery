I'd like to add a new refactoring assist to rust-analyzer that converts a plain struct variable binding into a destructuring pattern. Right now, when I bind a struct to a variable and later access its fields, there's no quick action to turn that binding into a destructuring pattern automatically. I have to manually rewrite the binding and track down all the field accesses to update them myself.

The assist should kick in when the cursor is on the variable name of a struct binding. It should replace the plain binding with a pattern that names all the struct's visible fields using the struct's type path, and it should update all existing field accesses on that variable in the same scope to use the destructured names directly. When a field was accessed through a reference expression, the reference should still be there after the substitution — only the field access part should change to the bare field name. For record structs with no naming conflicts, it should use the shorthand form where only the field name appears in the pattern.
