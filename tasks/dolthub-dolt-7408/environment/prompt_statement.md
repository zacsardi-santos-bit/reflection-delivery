I'd like to add a statistics flag to the Dolt log command so that when I browse commit history I can also see a compact summary of what changed in each commit — which tables were added or dropped, and how many rows were inserted, modified, or deleted. Right now the log output only shows the commit metadata (hash, author, date, message), and I have to dig into each commit separately to understand the scope of its changes. I'd expect this new flag to work alongside the existing option for compact single-line commit output, and I'd expect merge commits to be excluded from the diffstat since their changes are ambiguous.
