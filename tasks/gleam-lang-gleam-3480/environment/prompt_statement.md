I'm working on the Gleam language server and noticed that when I'm inside a function body, none of my locally defined variables appear in autocomplete suggestions. If I define a variable with a let binding or accept it as a function argument and then start typing its name, the editor gives me nothing — no suggestion at all. Module-level values and imported names show up fine, but anything I've defined locally in the current function is invisible to the completion engine.

I'd like the language server to suggest locally defined variables as completion items, showing each variable's inferred type. The completions should respect lexical scoping: variables defined after the cursor position shouldn't be suggested, and variables that belong to an inner anonymous function should only appear as suggestions inside that function's body — not in the outer scope. Discard bindings (names starting with an underscore) shouldn't be suggested either. Pattern match bindings, including those from destructuring tuples, lists, bit arrays, and string patterns, as well as pattern aliases should all appear as completions when in scope.
