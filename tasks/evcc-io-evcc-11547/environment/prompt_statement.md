We're currently using an older, archived mock library for Go testing throughout our codebase. The community has moved on to an actively maintained fork of that library. I'd like to migrate our project to use the current maintained version so we're not stuck depending on something that's no longer receiving updates.

This involves updating all the test files that import the old mock framework to point to the new one, regenerating all of our auto-generated mock files to use the new library, and updating our dependency manifest accordingly. For one specific charger type, the mock for the e-mobility interface should be generated locally within that charger's own module instead of being imported from an external library module — this way those charger tests are self-contained.
