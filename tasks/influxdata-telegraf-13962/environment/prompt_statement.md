I'm using the nvidia-smi input plugin to collect GPU metrics from a mixed fleet that includes some older Quadro-series GPUs. The newer GPUs report power draw just fine, but for the older Quadro cards the power draw metric is completely missing from the collected data. After digging into it, I found that the older GPUs report their power consumption under a different XML section name in the nvidia-smi output than the newer GPUs do. The plugin currently only knows how to read power data from the format used by newer GPUs, so the older format is silently ignored.

I'd like the plugin to be extended to also support the older power reporting format so that power draw is correctly captured for these older GPU models too. All other metrics (memory, clocks, utilization, temperature, etc.) are collected correctly — it's only the power draw that's missing because of the different XML structure.
