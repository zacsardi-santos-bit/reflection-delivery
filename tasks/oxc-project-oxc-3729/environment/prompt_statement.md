I've noticed that the JavaScript minifier is always adding an extra semicolon at the end of its output, even when it's not needed. For example, if I minify a simple expression or a single statement, the result always has a trailing semicolon character at the very end. This is unnecessary — a trailing semicolon at the end of a file or snippet doesn't add anything, and it wastes a byte of output.

I'd like the minifier to stop adding this trailing semicolon. Semicolons that are genuinely needed inside the code — like between consecutive statements — should still be there, but nothing should be tacked on after the very last statement or expression in the output. This change should apply consistently for all kinds of JavaScript code: expressions, comparisons, logical operations, variable declarations, function and class expressions, arrow functions, assignments, exports, and everything else the minifier handles.
