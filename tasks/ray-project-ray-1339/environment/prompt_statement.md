I'm building a distributed reinforcement learning system where multiple remote workers each collect experience and maintain their own running statistics for normalizing observations and rewards. The problem is that right now there's no way to bring all those per-worker statistics together and keep the workers in sync with each other. I need a filter management utility that can reach out to all the remote workers, pull their accumulated statistics, merge everything into a central copy, and then push the updated state back to every worker so they're all on the same page.

On top of that, the individual filter objects need a few new capabilities: the ability to apply another filter's accumulated buffer on top of themselves (optionally also copying that buffer), the ability to clear their buffer, and the ability to fully sync themselves from another filter. The underlying running statistics tracker also needs to support merging two independent trackers into a single combined one that reflects all the data both saw.

I also need the asynchronous gradient optimizer to work correctly end-to-end, such that calling a single training step applies exactly the configured number of gradient updates to the local model using gradients collected from the remote workers.
