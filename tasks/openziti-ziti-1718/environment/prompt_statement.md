I'm working on the router and I'd like to add a configurable startup timeout for connecting to a controller. Right now, there's no way for operators to control how long the router waits during startup before giving up if it can't reach a controller. In some environments the network is slow or the controller takes a while to become available, so we need to be able to tune this. I'd like to add a new optional setting in the router's controller configuration section that lets operators specify a startup duration, and the configuration structure should expose this as a duration field that can be set and read by the router.
