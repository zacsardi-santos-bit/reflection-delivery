I'm working with an offline reinforcement learning library that has a great implementation of Implicit Q-Learning for continuous action spaces, but I need to use it in environments where the agent selects from a discrete set of categorical actions (like games or navigation tasks). Currently there's no discrete-action variant of this algorithm in the objectives module, which means I can't apply offline IQL training to my environment without hacking the continuous-action version.

I'd like a new loss module specifically designed for discrete action spaces to be added to the objectives package. It should take an actor network, a value network, and one or more Q-value networks, and produce three independent loss terms — one for each component — plus an entropy estimate. Critically, when I backpropagate any one of those individual losses, the gradients should only flow to the relevant network and not bleed into the others. The module should also support a temperature parameter and an expectile parameter (for the value regression), and an option to handle shared layers between networks in a way that keeps each loss truly isolated.

The module should integrate with the existing value estimator framework, support configurable tensor key names, be serializable via state dicts, and also accept plain keyword arguments in addition to structured tensor containers. It would also be very helpful to have a runnable example training script showing how to use it end-to-end, similar to the existing examples in the repository.
