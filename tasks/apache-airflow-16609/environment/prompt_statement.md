I'm working with Airflow's REST API and I can retrieve user information just fine, but I need the ability to also create, update, and delete users through the API. Right now those operations don't seem to be supported — there are endpoints for reading users but nothing for writing.

I need to be able to create a user by posting their details (username, password, email, name), with optional role assignments. If I don't specify any roles, the system should assign the default public role automatically. I also need to update an existing user's details or role assignments (with support for only applying changes to specific fields using an update mask), and delete a user entirely.

For all of these write operations, the API should enforce authentication and authorization properly: unauthenticated requests should be rejected with a 401, requests from users without the right permissions should get a 403, and trying to create a user that already exists should return a 409. Trying to update or delete a nonexistent user should return a 404. When the request body has problems — like missing required fields, unrecognized field names, or role names that don't actually exist in the system — the API should return a 400 with a clear message explaining what was wrong.
