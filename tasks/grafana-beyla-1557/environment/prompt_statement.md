I'm working on Beyla and I'd like context propagation — the feature that injects trace headers into outgoing HTTP requests via the Linux kernel's traffic control subsystem — to be enabled by default rather than requiring users to explicitly turn it on. Right now, if someone deploys Beyla without configuring anything special, context propagation is off, which means distributed tracing between services doesn't work until they know to flip that option. I'd like it to be on by default so that distributed tracing works out of the box, while still allowing users to disable it if they need to.
