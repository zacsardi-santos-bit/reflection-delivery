I'm working on the server package for a JavaScript CDN and need to replace the current JSON-based storage of build metadata with a more compact, custom encoding. Each build produces metadata that tracks several properties: whether the module uses the CommonJS format, whether it has associated CSS, whether it is types-only, whether it exports a default, what TypeScript definition file path is associated, and what other modules it imports.

I need a pair of functions that can encode this metadata into a compact byte representation and decode it back to the original structure, with full round-trip fidelity. Encoding a fully populated metadata record should produce a non-empty result, and decoding it should return the same values without any loss. Encoding and decoding an empty (zero-value) metadata record should also work correctly — all boolean fields should come back false, the definitions path should be empty, and there should be no imports listed.
