I'm working on the Avatar component in our React Native design system and I've noticed a bug: when an Avatar has no photo and no initials, it should show a person silhouette icon as a fallback — but in High Contrast mode, this icon doesn't appear at all. The Avatar just shows a blank circle.

After digging into the rendering, I believe the problem is that the fallback icon is being routed through the generic icon slot, which wraps the SVG element in an extra view. That wrapper prevents the SVG from inheriting the theme's foreground colors, which is how High Contrast mode colorizes everything. As a result, the icon renders with no visible color.

The fix should involve introducing a dedicated slot for the fallback icon that renders the SVG element directly — without any intermediate wrapper — so the icon can properly inherit colors from the theme. The icon's dimensions should also be explicit numeric values (derived from the component's size token) rather than relative percentages, and the slot should receive its color and size styling from the appropriate icon tokens. This would make the person silhouette visible in High Contrast mode just like it is in regular themes.
