I'm working with a library that provides streaming-mode path utilities — wrappers that make path operations like joining, opening, and reading files work transparently across both local paths and remote URLs. The library already handles most common path operations, but it's missing glob-style pattern matching. When I try to enumerate files matching a pattern (for example, all files with a certain extension, or all directories matching a date pattern), there's no utility for that — the glob and recursive glob operations don't have streaming-compatible equivalents.

I need two new path utilities added to the streaming download manager module: one that globs a directory for entries matching a pattern (returning each matching entry as a path), and one that does the same recursively across all subdirectories. Both should work the same way whether the path is a local directory or a remote location, consistent with how the existing path utilities in this module behave.
