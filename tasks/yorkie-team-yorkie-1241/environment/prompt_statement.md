I'm working on a collaborative document editor codebase and need two related improvements. First, the method for initializing a tree data structure currently requires passing a pointer to the initial node, but the rest of the API uses value types — this inconsistency is causing friction and I want the tree initialization to accept a value instead of a reference, across both the object and array APIs.

Second, and more importantly, I need a way to snapshot the full live state of a document and serialize it to a portable JSON format, then reconstruct the document from that snapshot. The document stores several CRDT types — objects, arrays, counters, plain and rich text, and trees — and the serialized snapshot needs to preserve the type information for each so the document can be faithfully reconstructed. I'd like a new package that defines typed representations for each of these CRDT value types, provides a conversion function from the live CRDT state to these typed representations, and implements marshal and unmarshal operations on each type. The serialized format should be compact JSON that can reliably round-trip. Any implementation errors during deserialization — like invalid data formats, wrong type codes, or malformed nested structures — should return descriptive error messages.
