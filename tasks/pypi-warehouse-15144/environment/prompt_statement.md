I'm working on adding Google Cloud as a trusted publisher option to PyPI, alongside the existing GitHub Actions support. Right now the trusted publishing system only supports GitHub, but we need to extend it so that project maintainers can also register Google Cloud workload identities as trusted publishers — both as pending publishers for new projects and as publishers for existing projects.

The publishing management views need to be updated so that both the account-level and project-level publishing pages show a form for registering Google-based publishers, display whether each provider (GitHub and Google) is enabled or disabled by administrators as a per-provider status flag, and support adding and removing Google publishers with the same flow as GitHub publishers. Administrators should be able to disable Google trusted publishing independently of GitHub trusted publishing.

When a provider is disabled by an admin, trying to add a publisher of that type should show a clear error message naming the disabled provider. Event logs and metrics should correctly identify Google publisher operations as being for the Google provider. The Google trusted publisher model should store the relevant Google-specific identity fields, and the publisher URL for Google publishers should be handled gracefully when it doesn't exist.
