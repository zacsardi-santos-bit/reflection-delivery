I'm working on the workspace settings feature for managing custom report fields. We need to implement the action that creates a new report field for a workspace. The creation should be optimistic — the field should appear in the workspace right away without waiting for the server — and the pending indicator on the field should be cleared once the server confirms the change. I also need a utility function that deterministically generates a unique field ID from the field's name, which will be used to compute the key under which the field is stored in the workspace's field list.
