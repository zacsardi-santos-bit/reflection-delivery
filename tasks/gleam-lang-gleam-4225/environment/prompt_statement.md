I'd like the Gleam language server to offer a code action that converts a pipeline expression into an equivalent regular function call. When I'm writing code that uses the pipe operator to chain a function call, it would be really helpful to have a quick editor action to rewrite that expression as a direct call instead — without having to do it by hand.

The action should handle all the usual forms: simple cases where the piped value becomes the first argument, bare function references without parentheses, module-qualified function references, empty-parens calls, and pipelines where there's an explicit placeholder argument (whether it appears in the first position or somewhere else in the argument list). It should also correctly handle the case where the function on the right side of the pipe already has all its arguments and produces another function, meaning the piped value ends up being applied to the result.

When there are multiple chained pipe steps, only the first step should be converted — the rest of the chain should remain as a pipeline. The action should appear as a refactoring option in the editor when the cursor is on or near the pipeline expression.
