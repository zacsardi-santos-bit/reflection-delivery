I'm working on the dashboard's JSON schema utilities and need to add a few utility functions for working with schemas programmatically. Right now there's no standard way to convert a known value (a string, number, or integer) into its corresponding JSON schema representation, check whether a value actually satisfies a schema's constraints, or extract the constant value that a restrictive schema encodes.

I need three utility functions exported from the JSON schema utilities module. The first should convert a constant value to a schema — returning nothing if no schema can represent it. The second should check whether a given value matches a schema, handling type constraints (string, number, integer), exact constant equality, and numeric "multiple of" constraints (where exact integer multiples match but non-integer multiples like N × 1.5 do not). The third should extract the constant value from a schema and return it as the first element of an array, so callers can retrieve the encoded constant.

These three functions together should support a round-trip guarantee: converting a value to a schema and then extracting the constant back always recovers the original value, and the original value should also match the schema it was converted from.
