I'm working on adding a new code action to the Gleam language server that helps developers understand the syntactic shorthand expressions in Gleam. The shorthand lets you write callback-style code in a sequential manner, but newcomers often don't know what it expands to. I'd like an editor action that, when the cursor is inside one of these shorthand expressions, offers to automatically rewrite it into the equivalent expanded form — a plain function call with the remaining block wrapped in an anonymous function passed as the last argument.

The action should handle the common cases: shorthands with no arguments, with existing arguments that should be preserved, with no bound variables, with one or more simple variable bindings, and with type-annotated bindings (the annotations must be kept). When there are nested shorthands, the action should apply to whichever one the cursor is currently sitting inside, not necessarily the outermost one. The action shouldn't be offered at all when the shorthand uses complex destructuring like tuples or literals, since those can't be expressed as simple function parameters.
