I'm trying to integrate AWS Glue Data Quality checks into my Airflow pipelines, but there are no built-in Airflow components for this. I'd like to be able to create and update data quality rulesets, start evaluation runs against my data tables, and monitor those runs until they complete — all from within a DAG.

Specifically, I need a hook that can check whether a ruleset exists and validate evaluation run results (logging how many rules failed and raising an error if any did). I also need operators to create or update rulesets and to start evaluation runs, with both supporting input validation and proper error propagation from the underlying API. The evaluation run operator should return the run ID and support waiting synchronously, polling with a waiter, or deferring.

For monitoring, I need a sensor that polls for the run status and returns success when it completes, or raises a failure (with a descriptive error message including the run ID, status, and error string) when the run enters a failure state. The sensor should support soft-fail mode and deferrable execution. Finally, a trigger is needed to support the deferrable path, which should use a custom waiter and signal completion with both a success status and the run ID.
