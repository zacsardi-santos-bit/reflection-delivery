I'm working with the Scaleway Terraform provider and I need to add support for configuring a recurring cron schedule on serverless job definitions. Right now, the job definition resource doesn't have any way to specify when a job should automatically run on a schedule — you can set the name, image, CPU and memory limits, but there's no scheduling option at all.

I'd like to be able to add a cron block to the job definition resource with a schedule expression and a timezone. The schedule should be created when you apply the resource with the block present, updated in-place when you change the expression or timezone, and deleted from the API when you remove the block from your configuration entirely. After each operation, the Terraform state should accurately reflect whether a cron schedule is configured and what its values are.
