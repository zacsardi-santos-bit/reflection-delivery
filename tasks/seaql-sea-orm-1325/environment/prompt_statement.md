I'm working with an ORM and I want to use specific UUID format types as entity model field types. Right now, only the plain UUID type is supported as a model field — if I try to use one of the formatted variants (like the hyphenated, braced, simple, or URN format wrappers), the ORM doesn't know how to read those values back from the database. I'd like the ORM to natively support all four standard UUID format wrapper types as entity model field types, so I can insert and retrieve records with those fields without needing any manual conversion. I'd also like vectors of these formatted UUID types to work as array column field types for databases that support arrays. Essentially, the formatted UUID types should be treated just like the plain UUID type when used in entity models.
