I'm working on the chain store in graph-node and want to simplify how block timestamps are returned when looking up a block by its hash. Right now the method that retrieves a block's number, timestamp, and parent hash wraps the timestamp in an internal time abstraction, which forces every caller to convert it to a raw integer before they can actually use it. I'd like to change the return type so the timestamp comes back as a plain unsigned integer (seconds since the Unix epoch) directly, without any wrapper. Blocks that don't have a timestamp should return nothing for that field instead of a sentinel-valued wrapper. The method should also be renamed to something that more clearly describes what it returns — the block's number and associated metadata — rather than implying it returns a "pointer."
