I'm working on the Cairo documentation system and need to add the ability to retrieve a formatted item signature together with the positions of all type references embedded in that signature. Right now I can get a signature string for a given item, but I have no way to know where the referenced type names start and end within that string — which makes it hard to turn them into clickable links in the rendered documentation.

I need a new query that takes any documentable item and returns both the formatted signature string (or nothing, for items that don't have signatures) and a list of start/end character positions within that string marking every referenced type. If a type can't be resolved at all, the signature should substitute a placeholder token and omit any link for that position. The fix to the formatting inconsistencies should also be applied so that the existing signature output is correct.
