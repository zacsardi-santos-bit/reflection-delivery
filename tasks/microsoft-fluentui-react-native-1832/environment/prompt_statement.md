I'm working on the experimental Text component in our React Native design system and I've noticed that it doesn't properly handle accessibility tap gestures. When a screen reader user double-taps on a text element that has a press handler, nothing fires — the accessibility tap and the regular press action aren't connected. I'd like the text component to automatically bridge these two so that the accessibility tap gesture invokes the same handler as a regular press, unless a custom accessibility tap handler has been explicitly provided. Since this text component is shared across many other components in the system (tabs, menus, badges, notifications, etc.), fixing it in one place should propagate the improvement everywhere.
