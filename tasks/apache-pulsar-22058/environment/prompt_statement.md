I'm working on adding OpenTelemetry metrics to the Pulsar broker and need a small utility to convert durations into seconds as a floating-point value. The problem is that the standard time unit conversion truncates to integers, so a 1-millisecond duration becomes 0 seconds — which completely loses precision for sub-second events. I need a shared helper in the common stats utilities that takes a numeric duration and a time unit and returns the exact equivalent in seconds as a double. For example, 1 millisecond should give 0.001, 1 microsecond should give 0.000001, and 1 nanosecond should give 0.000000001, while whole units like hours and minutes should also work correctly (1 hour → 3600.0, 1 minute → 60.0). This utility will be used across broker components that emit duration metrics so the conversion logic doesn't get duplicated everywhere.
