I'm working on Pomerium, which often runs behind an Envoy proxy. I need a utility function in the HTTP utilities package that reliably returns the client's real IP address from an incoming request. The tricky part is that when traffic goes through Envoy, the real client IP comes in via a special forwarded-address header rather than being directly visible in the connection's remote address. The function should check that header first, and if it's not present, fall back to parsing the IP from the raw remote address (stripping any port suffix). If neither is set, it should return the loopback address as a safe default. I'd like this to live in the internal HTTP utilities package so it can be shared across the codebase.
