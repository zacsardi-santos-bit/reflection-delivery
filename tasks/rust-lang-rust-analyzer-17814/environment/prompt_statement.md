I'd like rust-analyzer to show object safety information when hovering over a trait. Right now if I hover over a trait definition, I get its signature and documentation, but there's nothing that tells me whether the trait supports dynamic dispatch. I often run into compiler errors about traits not being object-safe, and it would be really helpful to see that information directly in the IDE without needing the compiler to tell me after the fact.

The hover output for a trait should indicate whether it is object-safe, and if it isn't, it should say why — for example, if a method is missing a receiver, or if the trait requires the implementing type to be sized, or if a method has generic type parameters, and so on. This would make it much easier to understand and fix issues when trying to use traits as dynamic trait objects.

To support this, the analysis layer needs a way to enumerate all the object safety violations for a given trait. The violations that need to be detected include: the trait itself requiring the implementing type to be sized, associated type bounds referencing the implementing type, associated constants, generic associated types, non-object-safe supertraits, and per-method violations such as missing receivers, generic type parameters, references to the implementing type in parameter or return types, and receivers that cannot be dispatched. Methods with a bound requiring the implementing type to be sized should be exempt from these method-level violations.
