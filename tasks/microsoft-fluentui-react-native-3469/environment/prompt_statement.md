I'm building a React Native UI library and I need to add a set of overflow components that aren't there yet. The idea is: when you have a row of items in a container and the container is too narrow to show them all, the ones that don't fit should be hidden and instead appear in a dropdown menu. Right now there's nothing in the package to handle this automatically.

I need three things added under the experimental overflow package. First, a container component that wraps all the items, accepts a list of all item IDs upfront, and manages which ones are visible. The container should be invisible by default while it figures out the layout (to avoid flash-of-content issues), then appear once it's done its first pass. Second, an item wrapper component that each individual item is wrapped in — identified by a unique string ID — which should pass layout and style callbacks directly down to its child without introducing any extra wrapper element in the tree. Third, a hook that a custom overflow menu component can call to find out: should the menu be shown right now (it should say yes by default before the first layout runs), and which item IDs are currently overflowing and should appear as menu options.

The container, items, and hook all need to work together so the container can calculate how much space is available, decide what fits, and keep the overflow menu in sync with which items are hidden.
