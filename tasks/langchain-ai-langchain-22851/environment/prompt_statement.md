I've been working with chat prompt templates that include message history placeholders — some marked as required and some as optional. When I inspect the JSON schema that describes what inputs the template expects, I notice that the schema never includes a list of required fields. This means that even variables that are clearly mandatory (and will fail validation if omitted) appear indistinguishable from optional ones in the schema.

This is a problem because I'm relying on the schema to tell downstream consumers which inputs they must provide. Right now, if someone checks the schema and sees no required fields, they might skip a required input entirely and only get a runtime error later. Ideally, required inputs — whether they're regular template variables or non-optional message placeholders — should be clearly listed as required in the schema. Optional placeholders should not appear there. And if someone tries to use the schema to validate inputs and they've omitted a required field, the validation should fail with an appropriate error rather than silently succeeding.
