I'm working on the Prowler cloud security API and need to add a new endpoint to the findings resource that returns a summary of which cloud services and regions are affected by findings. The endpoint should support filtering by date and severity, returning only the distinct services and regions from the findings that match those filters. When no findings match the filters — for example, when filtering for a date far in the future — the endpoint should return empty lists for both services and regions rather than an error. When an invalid date is provided as a filter, the endpoint should return a proper validation error with a clear message indicating the date format problem. This would allow dashboards and reporting tools to quickly understand the scope of affected cloud services and regions without having to fetch and process all findings individually.
