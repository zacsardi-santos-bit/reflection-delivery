I often find myself writing Gleam code where an outer case expression matches a value to extract a variable, and then immediately I need another case expression that matches on that extracted variable. This produces unnecessarily nested code that would be much cleaner as a single flat case expression.

I'd like the language server to offer a code action that collapses these two nested case expressions into one. When I place my cursor on the relevant variable, the action should merge the two levels into a single case expression by combining the outer and inner patterns for each clause.

The action should handle all the usual edge cases: when the inner case is wrapped in a block, when the outer pattern has multiple bound variables (only replacing the relevant one), when constructor patterns use labeled fields (keeping labels intact), when inner clauses use alternative patterns separated by pipes (distributing them across the outer pattern), when the matched variable is still referenced in the body (adding an alias so the name stays accessible), and when either or both levels have guard conditions (combining them with a logical and, adding parentheses around guards that use logical-or to preserve correct precedence).
