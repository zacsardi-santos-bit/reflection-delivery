I'm working on a release automation tool that resolves the current version, target version, and helm chart target version as part of a release process. Right now, there's no way to persist these resolved values to disk, which makes it hard to use them in downstream CI/CD pipeline steps without re-running parts of the release logic.

I'd like to add the ability to save the release version information to a file at a configurable path. When a file path is provided, the tool should write a simple text file containing all three version values in a labeled, line-oriented format — one version per line, each prefixed with its label — so that shell scripts in later pipeline stages can easily read them with standard tools. When no path is provided, the tool should just skip writing anything and carry on as normal.
