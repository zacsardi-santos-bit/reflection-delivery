I need to add an option to the HTTP client builder that lets users choose to send HTTP/1.1 request headers in title case format. Right now the client always sends header names in lowercase, which is spec-compliant, but some legacy servers I'm working with seem to expect headers to be capitalized in the usual way (first letter of each word after a hyphen is uppercase). I'd like to be able to opt into that behavior on a per-client basis without changing the default behavior for anyone else. The option should be chainable with other builder settings and should apply to actual outgoing connections, not just at the encoding layer.
