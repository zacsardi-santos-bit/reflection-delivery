I'm working on the checks feature in InfluxDB and I need to add an endpoint that returns the effective query for a given check. Right now, if you have a check configured with a source query and a run schedule, there's no way to see what the actual executable query looks like — the system adjusts the time range and appends task scheduling options at runtime, but you can't retrieve that final form through the API.

I'd like to add a handler on the check service that, given a check ID, looks up the check and returns a JSON response containing the generated query. The query should adapt the check's source query to use the check's scheduling interval for the time window, and include the task options at the end. The response should just be a JSON object with the generated query string.
