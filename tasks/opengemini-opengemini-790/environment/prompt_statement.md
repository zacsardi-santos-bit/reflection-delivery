I'm working on adding a gRPC-based record write service to openGemini. We need a service that clients can use to push batches of binary-encoded time-series records over a high-performance protocol. The service should start and stop cleanly, accept pluggable writer and authorizer implementations, and handle batch writes with three distinct outcomes: full success when all records are valid, failure when all records are invalid, and partial success when the batch contains a mix of valid and invalid records (with the valid ones still being written). The service also needs to respond to ping requests by reporting the server is up. Additionally, the service should support optional authentication — when enabled, write requests must include valid user credentials with write privileges; if the credentials are missing or the user lacks write access, the request should be rejected.
