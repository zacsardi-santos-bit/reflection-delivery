I'm cleaning up Polars' side of the dataframe interchange protocol import path (the code that pulls data in from other dataframe libraries) and it's got a bunch of correctness gaps I want fixed. Right now it leans on a third-party library as a middleman for the actual buffer construction, and I'd rather move that logic into the interchange module itself with clearly defined helper functions that build data buffers, offsets buffers, and validity buffers directly. Those validity helpers need to cover every null representation the protocol defines: non-nullable, bitmask, bytemask, NaN-as-null, and sentinel values, so the buffer construction is correct across all of them.

Concrete stuff I keep hitting: categorical / dictionary-encoded columns currently error out on import instead of coming in as the equivalent Enum type, and I want them mapped to Enum automatically including on zero-copy import where the data already supports it. Non-string category keys are a different story, those should raise a clear, actionable error saying non-string categorical keys aren't supported rather than crashing weirdly. Boolean data is also broken, some sources hand it over byte-packed and we don't handle that at all, so it should import fine when copying's allowed and otherwise raise a descriptive error explaining exactly why the zero-copy path isn't available for that column. Boolean columns in zero-copy mode from certain sources are mishandled too. Also empty boolean and empty categorical DataFrames should import without any copy.

Temporal types (durations and time-of-day) aren't supported through the protocol at all and they should be. Floating-point NaN values aren't being treated as null, fix that so NaN in float columns becomes a Polars null. And whenever a zero-copy conversion isn't possible, the error needs to be specific about what's blocking it, like naming when a bitmask has to be constructed or when an offsets buffer needs casting, so I actually know which column or buffer type is the problem. Point is, common types should round-trip the way people expect.
