I'm working on adding OpenTelemetry instrumentation support for the Mistral AI client library, similar to the existing instrumentation packages in this repo for other AI providers. Right now there's no way to automatically trace Mistral AI calls — neither chat completions nor embeddings requests — through OpenTelemetry.

I need an instrumentation package that, once enabled, automatically captures trace spans for all Mistral AI requests made via both the synchronous and asynchronous clients. For chat requests, the spans should record the model used, the input prompt content, the generated response content, whether streaming was used, and token usage (prompt tokens, completion tokens, and total tokens). For streaming responses, the span should collect all the streamed chunks and record the fully assembled response text. For embeddings requests, spans should record the model, the input text (or the first item if multiple inputs are provided), and indicate that it was an embedding request. Both streaming and non-streaming chat calls need to be supported, as do both sync and async versions of both chat and embeddings.
