I'm working on a shader compiler that processes WebGPU shading language (WGSL) shaders. The specification defines a flat interpolation mode with two additional sampling qualifiers — one for "first vertex" and one for "any vertex" — but my implementation doesn't recognize them yet. Shaders that use these qualifiers fail to parse, and even if they could be parsed, the validator doesn't know how to handle them and the code generation backends don't emit the right output.

I need to add support for these two new flat sampling qualifiers end-to-end: the frontend should parse them, the validator should accept them when paired with flat interpolation and reject them when paired with other interpolation modes (while also rejecting the centroid and sample qualifiers for flat interpolation), and all code generation backends should produce correct output. For backends that target SPIR-V, Metal shading language, HLSL, and WGSL, both new qualifiers should be treated as plain flat interpolation with no additional sampling decoration. For the GLSL backend specifically, the "first vertex" qualifier is not representable in OpenGL, so attempting to generate GLSL for a shader that uses it should return a clear backend error rather than producing invalid output.
