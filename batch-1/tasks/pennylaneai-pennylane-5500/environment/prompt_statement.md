I'm working on adding the qubitization algorithm to PennyLane as a native quantum operator. Qubitization encodes a Hamiltonian — expressed as a weighted sum of unitary operators — into a unitary whose eigenvalues encode the Hamiltonian's eigenvalues, making it useful for quantum phase estimation.

The operator should accept a Hamiltonian and a list of control qubits. It needs to decompose into a specific sequence: an amplitude embedding of the normalized coefficient magnitudes on the control register, a controlled selection of the Hamiltonian terms (with phase corrections applied to any terms with negative coefficients), the adjoint of that amplitude embedding, and finally a reflection. Negative coefficients should be absorbed into a global phase on the corresponding operator so that only positive magnitudes appear in the amplitude embedding.

I also need a helper function that transforms a Hamiltonian with mixed-sign coefficients into one with all-positive coefficients, returning both the absolute-value coefficients and the phase-corrected operator list.

The operator should satisfy all standard PennyLane operator validity requirements, produce identical results on different simulator backends, support wire remapping, support proper copying behavior where the copied operator does not share internal state with the original, work with both modern and legacy Hamiltonian representations, and be differentiable with respect to the Hamiltonian coefficients using common automatic differentiation frameworks. When used inside iterative quantum phase estimation, it should yield eigenvalue estimates that match the true Hamiltonian eigenvalues.
