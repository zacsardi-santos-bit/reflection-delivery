I'm adding qubitization to PennyLane as a native operator and could use help getting it right. The idea is qubitization takes a Hamiltonian written as a weighted sum of unitaries and encodes it into a unitary whose eigenvalues carry the Hamiltonian's eigenvalues, which is the key ingredient for quantum phase estimation. Right now folks who want to estimate eigenvalues via QPE have to hand-build the block-encoding, deal with phase corrections for negative coefficients, and stitch together the prep/select/reflect steps themselves, which is error prone and doesn't play nice with PennyLane's diff framework.

What I want is a new operator that takes a Hamiltonian (a linear combination of unitary operators) plus a list of control qubits, and decomposes into the standard sequence: an amplitude embedding of the normalized coefficient magnitudes onto the control register, a controlled selection of the Hamiltonian terms (with phase corrections applied to any term with a negative coefficient), then the adjoint of that amplitude embedding, then a reflection. Negative coefficients should get absorbed into a global phase on the matching operator so only positive magnitudes show up in the amplitude embedding. I also want a helper that transforms a mixed-sign Hamiltonian into an all-positive one, returning both the absolute-value coefficients and the phase-corrected operator list.

It's gotta satisfy all the standard PennyLane operator validity checks, give identical results across different simulator backends, support wire remapping, and copy properly so the copied op doesn't share internal state with the original (that one bit me before). It should work with both modern and legacy Hamiltonian representations, and be differentiable w.r.t. the coefficients using the common autodiff frameworks. And when I drop it into iterative QPE it should spit out eigenvalue estimates that match the true Hamiltonian eigenvalues. This'll probably live alongside the other subroutines, so wire it in wherever those templates go.
