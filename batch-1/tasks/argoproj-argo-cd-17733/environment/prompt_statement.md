I'm running into a bug with Argo CD's ignore-differences feature when the ignore rules target fields that live inside arrays. For example, I have a resource with routes that contain rate limit policies, and I want to ignore differences in the route entries entirely. But after normalization, the route entries are being replaced with empty objects instead of keeping the real data from the live resource. The same problem happens when I try to ignore a specific environment variable inside a container's env array — if my target manifest adds new env vars, they either go missing or the normalization corrupts the existing entries.

I'd expect that when an ignore rule selects elements inside an array, the controller should copy the live values for those ignored elements into the target, while still preserving any new entries that only exist in the target. Instead, the normalization is producing empty objects where there should be real data.

It would also be great if the fix correctly handles the case where the target has added more fields than the live resource (like new labels, resource requests, or env vars) alongside ignored fields like image or replica count — the ignored fields should take the live value, but all the new target fields should be included in the normalized result.
