We've got Modal and TooltipModal in our modals package but no DrawerModal, and I keep needing that slide-in-from-the-side pattern for showing detail views and forms and secondary content without yanking people off the page. Third-party stuff doesn't play nice with our Garden theming so I want to build it properly into the package.

I want a new `DrawerModal` component I can import from the modals package. It should slide in from the right side of the screen by default, and from the left when we're in an RTL layout, overlaying the content behind it. Build it as compound components so I get `DrawerModal.Header` for the title area, `DrawerModal.Body` for the main content, `DrawerModal.Footer` for action buttons with `DrawerModal.FooterItem` for each individual item in there, and `DrawerModal.Close` for the close button.

Behavior-wise it needs to lock page scrolling while it's open and restore scrolling when it closes. It should close when someone hits ESC, clicks the backdrop, or clicks the close button. Ref forwarding should work on all the elements, so I can grab refs on the drawer itself and each of the subcomponents. Oh and it takes an optional `id` prop that drives the accessibility attributes (things like aria wiring for the header and body relative to the drawer), so those attributes should be applied correctly based on whether that id is passed. Make sure it all fits our existing design system styling and theming conventions.
