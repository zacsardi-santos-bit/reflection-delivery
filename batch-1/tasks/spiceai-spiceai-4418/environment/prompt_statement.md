So I keep running into this thing where folks with newer or less common GPUs can't actually get hardware-accelerated AI inference even though their card is totally capable. The system detects the GPU fine, but then it silently drops back to CPU because the GPU's compute capability version isn't in some hardcoded allowlist of approved versions. End result is unnecessary performance degradation and no clear explanation to the user, they just get slow CPU inference and wonder why.

The real problem is that allowlist goes stale the second a new GPU generation ships. Anyone on the latest hardware with a newer compute capability version gets silently penalized, and someone has to remember to go update the approved list in code every time new cards come out, which obviously isn't happening.

What I want is to just rip out the version allowlist restriction entirely. If a GPU is detected at runtime, accept it, full stop, and return the appropriate accelerator identifier regardless of the specific compute capability version. Right now the code rejects unlisted versions and returns a "not found" result, so change that path so any successfully detected GPU counts as a valid accelerator and we signal that an accelerator was found. New GPU generations should just work automatically without needing code updates. So basically: detected GPU means valid accelerator, no version gatekeeping, always return the accelerator id plus the found signal in that case.
