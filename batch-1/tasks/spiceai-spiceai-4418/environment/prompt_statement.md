I'm running into an issue where users with newer GPU models can't get hardware-accelerated AI inference even though their GPU works fine. The system detects the GPU but then silently falls back to CPU because the GPU's compute capability version isn't in a fixed approved list. This means anyone with a recent GPU that wasn't on the original list just gets CPU performance without any clear explanation.

The fix should remove the version allowlist restriction entirely — if a GPU is detected at runtime, the system should accept it and return the appropriate accelerator identifier, regardless of the specific version. The current behavior of rejecting unlisted GPU versions and returning "not found" should be changed so that any successfully detected GPU is treated as a valid accelerator.
