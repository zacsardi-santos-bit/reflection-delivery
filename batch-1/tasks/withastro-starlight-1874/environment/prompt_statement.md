I'm working on a multilingual docs site with Starlight and the sidebar config is way more tedious than it should be. Every single page link makes me write out the label by hand even though the page already has a title sitting right there in its frontmatter, and for the multilingual case it's brutal because I end up copying locale-specific labels for every language when I've already got those titles defined in my translated content files.

What I want is to just reference a page by its slug in the sidebar config and have Starlight pull the page's frontmatter title in as the nav label automatically. For translated content it should grab the title matching the current locale, and if there's no translation for that locale it should fall back to the default locale's title. I'd also love to use a plain string as shorthand for these simple internal page references instead of always writing out an object. And I still want the option to override with a custom label, or per-locale label overrides, directly in the sidebar item config when I actually need that.

The error handling matters too. If I fat-finger a slug with a leading or trailing slash, I want a clear message that tells me what's wrong and suggests the corrected slug (the one without the slashes). And if I reference a page slug that doesn't exist in the docs collection, give me a descriptive error that points me at fixing the config rather than some cryptic failure. Basically this whole thing should keep the sidebar in sync with page content and kill the duplication between my site config and content files.
