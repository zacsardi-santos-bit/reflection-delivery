I want to add a shared internal zstd compression module so our subsystems stop each importing the third-party zstd library directly. Right now several packages (the conda and debian package handlers among them) reach for the third-party lib on their own, and there's no centralized wrapper, which makes it hard to keep behavior consistent or add extended stuff like seekable streams or swap the implementation later. So I'd like this new module to live in the project's internal module tree so those existing packages can just switch their imports over to it.

Two things I need from it. First, a plain streaming compress and decompress interface, basically you make a writer that compresses as you write and a reader that decompresses, and both take functional options for stuff like the compression level and a low-memory decode mode. Round-tripping arbitrary data through the standard writer and reader should just work.

Second, and this is the important part, a seekable variant. The seekable writer splits the uncompressed data into fixed-size blocks as it compresses and builds an internal index off those blocks, so a reader can later jump straight to any byte offset in the uncompressed content without decompressing from the start. The seekable reader should seek to a given offset and read from there while only touching the relevant block or two, so seeking stays a small bounded number of underlying I/O ops rather than reading the whole file. Oh and when you close the seekable reader it should also close the underlying source if that source supports closing. Also the seekable reader should only accept data that was actually written in the seekable format, so if you hand it ordinary compressed data (like what the standard writer produces) it returns an error. But the reverse should hold too, data written in the seekable format needs to stay readable by the ordinary reader for backward compatibility. The payoff here is things like compressed action log storage with efficient partial viewing, all with dependency management in one place.
