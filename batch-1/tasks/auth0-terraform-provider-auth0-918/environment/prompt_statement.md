I'm building out our Auth0 setup with the Terraform provider and hit a wall: there's no resource for managing the custom HTML that gets injected into Universal Login prompt screens. I'm talking about the partials, the little chunks of markup you can drop into specific sections of a given prompt screen (login, signup, that kind of thing). Stuff like the content at the start of the form, the content at the end of the form, the footer area, and the secondary actions section. Right now I have to manage all this outside Terraform which totally breaks my IaC workflow, everything else is declarative and then this one piece is manual clicking or some separate script, not great for consistency or auditing.

So I want a new managed resource in the provider that lets me pick which prompt screen I'm targeting and give it HTML content for each of those injectable sections. It needs to handle the full lifecycle: create the customization, read it back into state, update individual sections (and here's the important bit, updating one section while leaving others empty should work and read back correctly), and clean it all up on destroy. Also when a section isn't configured I don't want it blowing up, it should just come back as an empty string in the state, not an error. And after an update the state read needs to reflect the new values properly.

Basically I want to declaratively manage the full appearance of the Universal Login experience without dropping out of Terraform for these prompt partials.
