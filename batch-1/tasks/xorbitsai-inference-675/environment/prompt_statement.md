I want to add GGML support for Qwen models in Xinference. Right now we only handle Qwen in PyTorch format, but folks want to run the quantized GGML builds for lower memory and faster inference, and the qwen.cpp project (https://github.com/QwenLM/qwen.cpp) gives us C++ bindings for exactly that through the qwen_cpp library. Problem is there's no integration for that backend, so when someone tries to load a Qwen model in ggmlv3 format it either falls back to LlamaCpp (which isn't compatible) or just can't find a matching model class.

So I need a new QWenModel class that plugs into the existing LLM infrastructure and knows how to run these quantized models via qwen_cpp. It should support both chat mode and plain text generation, both with streaming. In chat mode I want it returning properly formatted ChatCompletion responses, or ChatCompletionChunk objects when streaming. Generate mode should give back Completion responses, or CompletionChunk objects when streaming. Oh and it needs to respect the usual generate_config stuff, so max_tokens, top_p, temperature, and stream should all actually do something.

Also the model has to be downloadable from either HuggingFace or ModelScope, and it needs to pull down the associated qwen.tiktoken file alongside the weights since qwen.cpp needs that for tokenization. Basically I want ggmlv3 Qwen to feel like a first-class option next to the PyTorch path.
