I'd like to change this to instead read from the system's own installation history file — that way, we don't depend on an external tool and the detection works reliably across environments.

Second, there's no method yet to query the software update service and find out what Command Line Tools package is currently available. I need a method that runs the update listing command and parses the output to return the package label. When no Command Line Tools package shows up in the listing, it should return nothing. This will allow us to determine the right package to install or upgrade.
