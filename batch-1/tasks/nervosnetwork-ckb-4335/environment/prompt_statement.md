I'm working on the CKB blockchain codebase and I'd like to improve the organization of test utilities. Right now, there's a bunch of useful test helper code — things like mock chain builders, transaction factories, cellbase creators, and reward calculators — that lives inside the chain crate's local test module. This means no other crate in the project can use these helpers without duplicating the code.

There's already a shared test utilities crate in the project specifically meant for this kind of thing. I'd like to move all those common test helpers into that shared crate, update the chain crate's local test module to remove the now-redundant implementations, and make sure all the existing chain tests still work by importing the shared versions. The dependency that was only needed in the chain crate because of those helpers should be moved to the shared utilities crate instead.
