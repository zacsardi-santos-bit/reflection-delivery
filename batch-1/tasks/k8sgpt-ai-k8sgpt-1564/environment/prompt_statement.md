I'm working on extending k8sgpt to cover resources managed by the Operator Lifecycle Manager, which is commonly used in OpenShift and other Kubernetes distributions. Right now k8sgpt has no analyzers for any of these OLM resource types, so problems with operator installations, catalog sources, subscriptions, and operator groups go completely undetected.

I need analyzers for five OLM resource types: catalog sources (flagging any that are in a non-ready connection state), cluster service versions (flagging any that haven't reached the succeeded phase), install plans (flagging any that failed to complete), operator groups (flagging namespaces that have more than one operator group, since that breaks operator resolution), and subscriptions (flagging any that are not at the latest known state). Each analyzer should include relevant details from the resource's status conditions in its reported error, and should silently ignore resources that are in a healthy state. All five should be registered so they can be used alongside the existing built-in analyzers.
