I'm building out the experimental icon package in our React Native design system and there's a gap I keep running into: we've got no way to render icons that ship as font files. Tons of icon sets distribute this way, where each glyph is just a Unicode character sitting at some numeric code point, and right now anyone who wants one has to hack together a one-off which is inconsistent with the rest of the library. I want a proper font icon component so this is a first-class thing.

Here's what I'm after. The component takes a font family name, a numeric codepoint, a color, and an optional font size, and it renders the character matching that codepoint styled with those values (right font family, right color, correct glyph). It should render as a plain text element with the character as its only content, no extra wrapping views or anything, so it drops into existing layouts cleanly. One subtle bit on the font size: when nobody passes a size, I still want the size to show up as a field in the style object (present but with no value), rather than being dropped from the style entirely, so the shape stays predictable. Oh and it needs to be stable across re-renders, same props in means same output out, no flickering or inconsistent results.

Wire it into the package's public surface too so other parts of the app can import it by name from the experimental icon package.
