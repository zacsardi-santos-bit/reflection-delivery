I'm in an Nx monorepo that runs Playwright for e2e tests and I keep hitting a gap in the generated Playwright configs. When these e2e projects got scaffolded, the config files came out without the browser project definitions, you know, the `projects` array that tells Playwright which browsers to run against like Chromium, Firefox, and WebKit. Without that section cross-browser runs are basically incomplete or just don't do what you'd expect, and anyone who set up their Playwright e2e stuff before this got fixed is stuck with configs that lack browser targeting. I don't want every dev manually patching each config file when they upgrade, so I want a migration that handles it for me.

What I need it to do is walk all the projects in the workspace, find each one's Playwright configuration file, and for any config that's missing browser project definitions go ahead and add default entries for Chromium, Firefox, and WebKit using the matching device descriptors (the `devices['Desktop Chrome']`, `devices['Desktop Firefox']`, `devices['Desktop Safari']` style ones). It also needs to add the browser device import at the top of the file so the updated config is actually valid, oh and if a config already defines browser projects leave it completely untouched, don't reorder or rewrite anything there. So the whole thing is: detect the incomplete ones, fill in the missing browser projects plus the import, skip the ones that already have them.
