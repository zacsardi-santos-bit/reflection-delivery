I'm working with Daft DataFrames and I keep hitting this wall where I have to name every single column explicitly whenever I want to apply an operation across all of them, which gets super verbose on wide frames. I want a wildcard expression so I can reference all columns at once, like multiplying every column by a scalar or summing all columns in a single concise expression instead of listing them out. Oh and I've got struct columns too, so I want a dot-star pattern (something like `col.*`) that flattens a struct into its individual fields during a select or aggregation, so if I have a struct with several fields I can expand them all into separate columns in one go.

This wildcard stuff should work everywhere I'd expect it, so selecting, aggregating, and exploding columns all need to handle it. Also I want to combine multiple wildcard expressions in a single operation as long as they're passed as separate arguments, since using two wildcards inside one expression tree (like adding a wildcard column to another wildcard column) is ambiguous and should just fail with a clear error.

For the error cases I really want descriptive messages, not confusing failures. If the wildcard pattern doesn't follow supported syntax (the star has to stand alone or be preceded by a dot-separator, anything else isn't recognized) I want an error saying the pattern isn't recognized. If I reference a struct via wildcard that doesn't exist, the error should name the missing struct. And if I apply a wildcard to a column that isn't actually a struct type, it should tell me clearly and name that non-struct column. The whole point here is cutting down the repetitive boilerplate so pipelines over wide or nested frames stay readable and maintainable.
