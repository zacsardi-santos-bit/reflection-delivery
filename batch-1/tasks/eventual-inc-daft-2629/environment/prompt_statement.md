I'm working with Daft DataFrames and I'd like to be able to select or operate on all columns at once instead of having to name each one explicitly. For example, I want to multiply every column by a constant in a single expression, or sum all columns without listing them. I'd also love a way to flatten struct columns — so if I have a column that's a struct with several fields, I can expand all those fields into individual columns in one go.

It would be great if this wildcard approach worked not just in selects but also in aggregations and explode operations. I'd also want multiple wildcard expressions to be combinable in a single operation as long as they're separate arguments (not mixed together in one expression tree, since that would be ambiguous). For cases where the wildcard doesn't resolve to anything meaningful — like referencing a struct that doesn't exist, targeting a column that isn't actually a struct type, or using an unsupported wildcard syntax — I'd expect a clear and descriptive error message rather than a confusing failure.
