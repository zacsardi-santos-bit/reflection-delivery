I'm working on improving the zsh-autosuggestions plugin in two ways. First, the plugin currently re-binds all its widgets on every single prompt, which is great for compatibility but really hurts performance. I'd like to add an option that lets users disable this automatic re-binding — when the option is set, widget list changes should not take effect on their own, and the user should be able to manually trigger the rebind whenever needed by calling the internal bind function directly. The bindings should work correctly after a manual rebind.

Second, when async suggestion mode is enabled and I start typing something (which triggers a background suggestion fetch), pressing Ctrl-C is supposed to cancel the current line and give me a fresh prompt. But with the current implementation, this doesn't work reliably. I'd like the async mode to be refactored so that Ctrl-C properly terminates the prompt and starts a new one, showing the aborted input on its own line followed by the new prompt.
