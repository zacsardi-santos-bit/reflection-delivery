I'm working on the BrickKit framework and need to implement an abstract base class for data models in Kotlin (replacing the existing Java version). The class should support an observer pattern where interested parties can register and unregister as listeners for change notifications. When changes are triggered on the model, every currently registered listener should have its notification method called, but any listener that was previously removed must not be called. The class should also provide a method to indicate whether the model is ready to be processed, returning true by default so subclasses can override it if needed. The nested listener interface should be defined inside the class itself.
