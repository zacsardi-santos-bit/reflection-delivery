I'm cleaning up our design system and we're bringing in a new generation of layout components, so the old flex-based stack stuff needs to be clearly marked as legacy so folks know it's on the way out. What I want you to do is rename the existing stack-layout components (the general flex container, the horizontal and vertical convenience wrappers, and the individual flex-item component) to all carry a "Legacy" prefix, both in the component names and in the file/folder layout so it's obvious in the tree. While you're in there, modernize the internals too: instead of expressing flex direction and alignment through inline styles, these should apply CSS module classes to reflect direction on the container and alignment overrides on the item. Oh and the CSS custom property names used for sizing and spacing should get switched over to a consistent design-system-specific prefix, and the legacy item should always set all of those sizing/spacing custom properties to non-empty values.

Externally these should behave exactly like they did before. The container takes a direction prop for horizontal vs vertical and applies the matching module class, the horizontal and vertical wrappers always force their direction using those same classes, and individual items can override their own alignment. Spacing gaps should apply to all but the first valid child, so when a gap is set only the second and later valid element children get the spacing margin. The tricky part is that non-element children (conditional renders that evaluate to nothing, plain text nodes, that kind of thing) at the start of the list must not count as the first child for spacing purposes, they should just be ignored when deciding who gets first-position treatment. And keep supporting the usual HTML customization props, custom element type (like an `as` prop), inline styles, and extra class names, on all of these. It's really just a rename plus a styling-mechanism swap, so nothing about the public API should actually change, it's just clearer now which layout components are current and which are being phased out.
