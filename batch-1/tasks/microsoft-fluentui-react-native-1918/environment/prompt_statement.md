I'm cleaning up the Badge component in our design system and there are two annoying things I keep hitting. First, the badge container uses a fixed height per size variant right now, so when the content is taller than we planned (text wrapping, a bigger image, whatever) it just clips or overflows. I want to switch that to a minimum height instead so the badge can grow to fit its content while still respecting the intended minimum size for each variant. It should keep the design dimensions as a floor but be allowed to expand vertically.

Second thing, the text inside the badge doesn't apply any font styling at all, so it just inherits whatever's around it and looks inconsistent everywhere it's used. I want the badge to explicitly set a font family (the primary one from the design system theme), a font size that fits each size variant, a semibold weight, and some horizontal padding around the text. For the "large" size specifically the font size should be 12, the font weight should be "600", the font family should resolve to "Segoe UI" from the theme, and the text padding should be 2.

Both of these need to land in the badge's token definitions and its styling config so all the size variants get updated consistently, not just large. Basically height becomes a min-height constraint and the text slot always renders with intentional typography instead of guessing at whatever's in the surrounding environment.
