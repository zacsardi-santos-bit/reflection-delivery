I'm working on this benchmarking comparison tool that spits out markdown reports comparing benchmark results across a few variants, and right now the per-harness data tables are all rendered fully expanded and flat inline. It's fine for small runs but the second you're comparing a bunch of benchmarks across multiple metrics the report turns into this giant wall of tables you have to scroll through forever, no way to collapse the stuff you don't care about right now.

What I want is for each metric's benchmark breakdown table to get wrapped in a collapsible section so readers can expand just the parts they actually want to look at. The collapsible bit should have a visible label saying it's a "Breakdown by harness" so it's obvious what's hiding in there, and it should be collapsed by default so you get the high-level summary first and then drill into whatever metric you're curious about on demand. Nothing existing should be lost, all the same table data stays, it's just tucked behind the collapse now.

Oh and this needs to apply to every metric section in the output, not just some, so both the ratio-type metrics and the pass/fail success metrics get the same collapsible treatment consistently.
