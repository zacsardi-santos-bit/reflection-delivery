I'm working in the TheAlgorithms Rust repo and I want to add a factorial function to the math module that uses arbitrary-precision arithmetic so it doesn't blow up on large inputs. The problem is standard fixed-size integer types overflow really fast when computing factorials, like 21! already exceeds what a 64-bit unsigned integer can hold, so any existing factorial utility is pretty limited. I want results that are always exact no matter how big the input gets.

So the idea is a new factorial function backed by big integers (BigUint from the num-bigint crate, that kind of thing) living somewhere like `@src/math/factorial.rs`. It should take a non-negative integer and return an arbitrary-precision unsigned integer holding the exact mathematical result. Edge cases matter here, factorial of 0 returns 1 and factorial of 1 also returns 1, and something like 10 should come back as 3628800. Basically the usual recursive/iterative product but without ever overflowing.

Oh and it needs to actually be reachable from the math module, so wire it up and re-export it through `@src/math/mod.rs` so other parts of the library can call it. This just rounds out the math module with a correct implementation devs can rely on for any valid non-negative input.
