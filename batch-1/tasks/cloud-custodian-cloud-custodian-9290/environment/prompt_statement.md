I'm hitting a couple of walls with Cloud Custodian's AWS App Mesh support and it's making the whole thing unusable for me. First issue is filtering. When I write a policy against meshes to find ones where the egress filter is set to some specific restrictive value, it never returns the right stuff. Turns out the resource objects only carry the basic listing data (mesh name, ARN, owner) and none of the spec fields like egress filter settings or service discovery preferences. So the filter silently matches nothing useful. I think the describe call that fetches full mesh details either isn't firing or isn't getting merged into the resource before filtering runs, and it needs to happen for all resources before tags get fetched, in that order. Also the describe response nests the actual mesh data inside a sub-object, so the extraction logic in the App Mesh resource type over in `@c7n/resources/appmesh.py` needs to scope to that nested mesh object, not the top level.

Second issue is reporting. When I run the report command for CSV output, meshes are missing the creation date column entirely because that date field isn't declared in the resource type definition. Virtual gateways are worse, their ARN, name, and creation date all live inside a nested metadata sub-object and the report formatter over in `@c7n/reports/csvout.py` can only look up top-level fields, so the headers and values come out empty or wrong.

Both problems come back to the same gap, the App Mesh resource type definitions need to correctly say where name, date, and id fields live (including nested ones), and the reporting and filtering plumbing needs to support dot-notation field paths so nested values can be pulled out. So can you fix the App Mesh resource config so mesh filtering on spec attributes works and report output includes mesh name plus creation date, and virtual gateway output shows the full ARN from nested metadata, the gateway name, and the creation date also from nested metadata, and teach the formatter to resolve dot-notation paths for nested fields? Thanks.
