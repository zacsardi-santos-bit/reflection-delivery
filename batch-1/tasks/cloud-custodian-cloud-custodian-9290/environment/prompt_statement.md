The headers and values in the CSV output are just wrong.

Both of these issues point to the same underlying gap: the App Mesh resource type definitions need to correctly declare where the name, date, and identifier fields are located (including for nested fields), and the reporting and filtering infrastructure needs to support retrieving values from nested paths using dot-notation.
