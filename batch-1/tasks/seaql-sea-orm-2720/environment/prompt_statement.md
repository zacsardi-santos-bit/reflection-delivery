I'm working with partial models that include active enum fields. When I specify a table alias on a partial model struct, the generated SQL no longer includes the necessary type cast for enum-typed columns. For example, without the alias the query correctly produces a cast expression for the enum field, but as soon as I add a table alias to the struct, the cast is dropped and the plain column reference is used instead. This causes broken queries on PostgreSQL.

The same issue appears with nested partial models: if I have a top-level struct with an alias and a nested partial model field with its own alias, the top-level enum fields lose their cast while the nested ones are fine. I need the type cast for enum fields to be applied consistently regardless of whether a table alias is specified, whether at the top-level struct or in combination with nested partial models.
