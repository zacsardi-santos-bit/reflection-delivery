I'm using the tracing crate for structured logging in my Rust application, and I've noticed that whenever I want to log both some structured fields and a human-readable message in the same event, I have to wrap my fields in curly braces. If I forget the braces, the macro doesn't compile. This feels unnecessarily verbose — I'd much rather be able to list my fields and the message together naturally, separated by commas, without any extra delimiters.

I'd like the tracing logging macros to support a "no-braces" syntax where I can mix named fields, local variable shorthands (including those using display or debug formatting sigils), and a format string message all in the same invocation, just comma-separated. This should work for the generic event macro as well as all the level-specific convenience macros. It should also handle trailing commas, invocations with an explicit target, and invocations that have fields but no message at all. Basically, the braces should become optional, and the macro should figure out where the fields end and the message begins.
