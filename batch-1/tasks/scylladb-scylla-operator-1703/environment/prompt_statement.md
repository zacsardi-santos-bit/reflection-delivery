I'm in the scylla-operator codebase and the resource-apply package is missing two helpers I need. That package already has apply helpers for a bunch of Kubernetes resource types and they all follow the same shape: compute a hash of the desired state, compare against what's in the cluster, create or update if needed, check controller ownership before touching anything, and emit info or warning events along the way. I want the same treatment for legacy endpoint records (Endpoints) and for the newer endpoint slice records (EndpointSlice), since both are currently absent and any controller managing endpoint stuff has to hand-roll its own reconcile logic, which is where the subtle bugs creep in (skipping the ownership check, clobbering externally added labels, not being idempotent, etc).

So each helper should create the resource if it doesn't exist, update it when the desired state differs from what's in the cluster, and do nothing when the stored hash matches the computed one so it's already up to date. They need to refuse to act on resources the controller doesn't own, and handle the annoying case where the local lister cache is stale relative to the API server (so a create that comes back already-exists should fall through to an update path rather than blowing up). Both need to be idempotent, calling them again with the same desired state and no external changes means no updates and no events at all.

Labels and annotations matter here too: anything externally added that isn't declared in the desired state should be preserved through updates, only the managed keys get changed. And when the desired object doesn't specify a resource version, use the existing object's resource version instead.

On events, emit informational events on create and update, warning events on failure, and none when nothing changed. Both helpers should also tolerate admission-webhook behavior the same way the existing helpers do. Please match the conventions and function signatures of the neighboring apply helpers in that package so it all reads consistently.
