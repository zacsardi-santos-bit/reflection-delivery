I'm adding a proper way to control which side the expand/collapse arrow icon shows up on in our collapsible panel component. Right now the arrow always sits on the left side of the panel header and there's no built-in prop to move it, so anyone who wants it on the right has to write custom CSS overrides, which is a hacky workaround. We even have a FAQ entry in the docs telling people to do exactly that, and I'd rather kill that entry once this lands.

So I want a new prop that controls whether the expand icon appears on the left or right side of the header. It should default to left so nothing breaks for existing users. Whatever position is currently active needs to be reflected as a CSS class on the component's root element so writing position-specific styles is easy, and that class has to respect whatever custom CSS prefix might be configured globally or per-component (so it can't hardcode the default prefix).

Also I want to update the demo that shows extra content inside panel headers to show this off interactively, oh and it should include a dropdown that lets viewers switch between left and right icon positions and see the panel update immediately. And once the prop exists, go remove that FAQ entry about manually repositioning the icon via CSS since it's no longer needed.
