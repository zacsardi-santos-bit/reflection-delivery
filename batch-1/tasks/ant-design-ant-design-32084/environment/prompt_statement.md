I'm working on our Divider component, the one that draws a horizontal line with an optional text label inside it, and it can align that label left, center, or right. Problem I keep hitting is that when the label's aligned left or right there's always this fixed default margin baked in between the label and the nearest edge, and I've got no way to override it. Sometimes I want the label flush against the edge (margin zero), sometimes I want a specific distance, and right now I just can't.

So I want to add a new optional prop that lets me control the margin between the label and its closest edge, overriding the default. It should accept either a string or a numeric value, so I can pass a string zero for no margin at all, or a number for a specific pixel distance, whatever the layout needs.

Behavior I'm after: when I set a custom margin on a left-oriented divider, the component should tack on a special CSS indicator class to the container element signaling the default left margin's been overridden, and set the label span's left margin inline to my value. Same deal mirrored for right orientation, indicator class on the container plus the label's right margin set inline. Left and right need to work independently. Oh and this prop should only kick in when orientation is left or right, center ignores it. Without this we just can't position labels flush or at custom distances, which is limiting for layout and design.
