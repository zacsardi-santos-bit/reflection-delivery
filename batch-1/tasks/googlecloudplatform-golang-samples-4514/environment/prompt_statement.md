I'm adding Go samples to the GoogleCloudPlatform/golang-samples repo that show how to use the Vertex AI model evaluation service, because right now there's nothing in Go for it and folks building AI apps who want to check the quality of their generative model outputs have nowhere to look. I want three standalone samples living together in a new package under the vertexai directory (so a fresh dir like `@vertexai/evaluation/` with its own go.mod module definition), each one a function that takes an `io.Writer`, a GCP project ID string, and a location/region string, and returns an error.

First one does ROUGE scoring, basically compares a model's generated text against a known reference answer using the text similarity metric and pulls out the resulting score, then writes it to the output writer. Second one evaluates a single model response for groundedness, how well it's supported by a given context, and writes out the score plus the confidence and the explanation. Third one does a pairwise comparison between two model responses given some context and an instruction, and writes which response got judged better along with the confidence and explanation.

All three need to connect to the right regional endpoint for the evaluation service (something like `LOCATION-aiplatform.googleapis.com:443` built from the location arg), and please handle errors from client creation and from the API calls gracefully rather than swallowing them. Results go to the passed-in writer. btw keep them idiomatic so they read like the other samples in that repo.
