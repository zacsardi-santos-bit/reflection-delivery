I'm running the nvidia-smi input plugin across a mixed GPU fleet and I keep hitting a gap with our older Quadro-series cards. The newer GPUs report power draw fine, but on the older Quadros the power draw field is just completely missing from the collected metrics. Everything else comes through okay (memory, clocks, utilization, temperature, fan speed, all of it), it's only power that drops out.

I dug into the actual nvidia-smi XML and it turns out the older cards report power consumption under a different XML element/section name than the newer ones do. The plugin over in `@plugins/inputs/nvidia_smi` currently only knows how to parse the newer format's power section, so when it hits the older layout it just silently ignores it and the value never makes it into the metric.

What I want is for the parsing to handle both the older and newer power reporting formats, so that when it sees an older Quadro-style card it still pulls the correct numeric power draw value and includes that field alongside all the other standard GPU metrics. Newer GPUs should keep working exactly as before, this is purely additive. Basically the plugin should recognize either XML structure and extract power draw from whichever one is present so mixed fleets get complete power numbers everywhere, not just on the data center cards.
