I'm working on the Winch JIT compiler and I need to add support for bitwise atomic read-modify-write operations on shared memory. Right now, Winch's x86-64 backend handles atomic addition, subtraction, and exchange operations, but it's missing the AND, OR, and XOR variants. When a WebAssembly module uses any of these missing bitwise atomic operations, Winch can't compile it — which means multi-threaded WebAssembly code that atomically manipulates individual bits in shared memory simply doesn't work.

I'd like to implement the full set of atomic bitwise read-modify-write operations for the x86-64 backend. This should cover all standard integer widths: 8-bit, 16-bit, 32-bit, and 64-bit variants, for both 32-bit and 64-bit integer result types. The implementation should produce correct machine code that atomically reads a memory value, applies the bitwise operation, writes the result back, and returns the original value — consistent with how the existing atomic operations work. Alignment checking for sub-word and multi-byte operations should also be handled the same way as in the existing operations.
