I'm working with an MLS group management library and I need to add support for embedding the ratchet tree in Welcome messages. Right now, when someone is invited to a group, they need to receive the ratchet tree separately through some out-of-band mechanism before they can join — there's no way to have the group automatically include it in the Welcome. I'd like to add a configuration flag to the managed group config that controls this behavior.

When the flag is enabled, the Welcome message sent to new members should include the ratchet tree, so they can join the group using just the Welcome message and no external ratchet tree. When the flag is disabled (which should be the default), things should work as before — but if someone tries to join from a Welcome without providing an external ratchet tree, the join attempt should fail with a clear, specific error telling them the ratchet tree is missing, rather than silently failing or panicking.

I need the configuration constructor to accept this new flag as a parameter, and I need the join-from-welcome operation to correctly succeed or fail based on whether the ratchet tree is available (either embedded in the Welcome or provided externally).
