I'm working on the virtlet image download subsystem and I've noticed that our image download and pull operations have no way to be cancelled once started. If a caller wants to abort an ongoing download — say, because a request was terminated or a deadline expired — the download just keeps running. I'd like to add proper cancellation support so that both the low-level download interface and the higher-level image pull operation accept a cancellation signal as part of their call signature, and correctly stop and return an appropriate error when that signal is triggered.

I'd also like to take this opportunity to refactor some duplicated TLS certificate utility code that currently lives in individual test files — it should be extracted into a shared test utilities package so it can be reused across the codebase without duplication.
