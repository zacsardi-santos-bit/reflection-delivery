I'm working on the Biome config migration tool and hit a gap around the file filtering changes in the latest major version. The old config used two separate fields, one for including files and one for ignoring them, and those now need to merge into a single unified field where exclusions are written with a negation prefix. Right now migration just leaves users to hand-convert all this, figuring out the glob syntax changes and merging include and ignore patterns themselves across potentially messy configs, so I want a new migration rule that detects the old separate-field style and offers a fixable diagnostic plus a code fix that does the merge.

The rule needs to fire everywhere these fields can show up, so top-level files settings, per-tool sections like the formatter, linter, and assists, and each entry inside the overrides array. When it finds the old fields it reports a fixable diagnostic and the suggested fix replaces both with the single unified field containing all the patterns transformed to the new glob format.

A few tricky bits: if only the ignore list is present with no include, the fix should prepend a catch-all wildcard so the exclusions still behave right. Also some glob patterns use syntax that isn't valid in the new format (single-character wildcards, character class brackets, that kind of thing), and each incompatible pattern should get its own informational diagnostic explaining why it can't be converted, and those patterns get omitted from the fix rather than breaking it. Oh and JSONC needs to work too, meaning inline comments and trailing commas, so parse those correctly and clean up any comments sitting between the two fields being merged as part of the fix.

Btw the spec test framework for migration rules also needs updating so it accepts JSONC input files not just plain JSON, parses inputs with comment and trailing-comma support, and requires a version file next to every spec instead of falling back to a default version. That means the existing specs that were leaning on the implicit default all need explicit version files added.
