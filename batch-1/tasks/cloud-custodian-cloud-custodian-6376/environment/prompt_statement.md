I'm trying to write governance policies for API Gateway using the cloud governance framework, but I'm running into two gaps. First, there's no way to list API Gateway client certificates as a standalone resource type — I'd like to be able to write a policy that returns all client certificates so I can report on them or apply actions. Second, I need to be able to filter API Gateway stages based on whether their associated client certificate has expired. Right now I can list stages but I can't inspect or filter on their client certificate properties. When a stage matches because of an expired certificate, I'd also want the certificate data attached to the stage resource so I know which certificate caused the match. Ideally this would also work when loading stages from AWS Config rather than directly from the AWS API.
