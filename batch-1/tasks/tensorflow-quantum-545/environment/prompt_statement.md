The noisy backend needs to support all the input combinations the layer already handles — batched circuits, batched operators (including 2D operator lists), symbol names and symbol values — and repetitions should be flexible enough to accept a single integer (applied to all operators), a 1D list (one per operator), or a 2D list (one per circuit-operator pair). Models using the noisy backend with enough repetitions should be trainable and converge on simple problems, even if the convergence tolerance is somewhat looser than the noiseless case.
