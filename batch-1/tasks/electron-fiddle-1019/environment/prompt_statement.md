I'm working on Electron Fiddle and hit a gap around download controls on Apple Silicon Macs. Older Electron versions (anything before version 11) don't have native ARM builds, so on an M1/M2 Mac those download buttons are basically lying to people, clicking them just leads to confusion or an outright failure since there's no downloadable ARM binary. Right now the app has zero awareness of this, it shows active download buttons for every version regardless of arch.

What I want is a small utility that looks at the current platform and CPU architecture and, given an Electron version string, tells me whether the download should be disabled. The rule is narrow: only disable on macOS when the architecture is ARM, and only for versions below 11. So Windows, Linux, and Intel Macs stay completely unaffected, everything downloadable as before, don't touch those paths.

Then wire that check into two places. The Electron settings panel that lists available versions should give each affected version entry a visual disabled state, and the version selector dropdown should show a tooltip element when a download is disabled so the user actually sees why. Basically anywhere a download is offered it needs to respect this arch guard. It's a growing class of users on Apple Silicon and they've got no in-app signal today that these older versions just can't come down for their machine, so making it clear here matters.
