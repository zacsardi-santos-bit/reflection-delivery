I'm adding OCI artifact support to CRI-O's seccomp handling and could use a hand wiring it up. Right now the runtime only knows how to load seccomp profiles from local files on disk or the built-in defaults, and there's no way to ship a profile as part of a container image in a registry and have it pulled automatically at container start. I want operators to be able to annotate a pod or container with a reference to an OCI image, and when that annotation is present CRI-O should pull the referenced image as a security artifact and read the seccomp profile file embedded in it.

There are three levels of targeting I need. First an image-level annotation baked into the container image itself, which only kicks in when no explicit higher-priority seccomp policy is already set. Then a pod-wide annotation that applies the referenced profile to every container in the pod. And a container-specific annotation that only applies to the named container. Oh and if the annotation key carries a container name suffix that doesn't match the current container, just ignore it. If no matching annotation is found at all, keep the existing behavior exactly as is.

The failure semantics matter: if a matching annotation exists but the pull fails, or the pulled artifact doesn't actually contain the expected seccomp profile file, I want it to return an error rather than silently falling back to defaults. And when something higher priority is already explicitly set (a locally specified profile, say, or the runtime default), skip the annotation-based path entirely.

So I need a new component that owns this annotation-checking and artifact-pulling logic, plus an update to the main seccomp setup flow so it calls into that component passing along the relevant annotation maps (image-level, pod, container) and the container name so the suffix matching works. Why bother? Shipping seccomp profiles as OCI artifacts alongside the workloads they protect makes distributing and versioning security policies way easier, no out-of-band file distribution to every node.
