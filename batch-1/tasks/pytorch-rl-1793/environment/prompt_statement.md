I'm using this offline RL library and the IQL implementation is solid but it's continuous-action only, and I'm stuck because my envs are all discrete categorical actions (games, navigation, that kind of sequential decision stuff), so right now I either hack the continuous version with awkward workarounds or bail to a different algorithm entirely. What I want is a proper discrete-action IQL loss module added to the objectives package so it behaves like every other loss module in there.

The gist: it takes an actor network, a value network, and one or more Q-value networks, and spits out three separate loss terms (actor loss, value loss, q-value loss) plus an entropy estimate. The big thing is these losses have to be independent, so when I call backward on any one of them the gradients only touch that network's params and don't bleed into the others. Even when networks share layers I want an option to treat those shared layers as separate during optimization so each loss stays truly isolated.

It should expose a temperature param and an expectile param for the value regression, plus a configurable number of Q-value nets. It needs to plug into the existing value estimator framework, so it should work with the standard TD estimators (TD(0), TD(1), and TD(λ)) and raise a sensible error if I hand it an estimator it doesn't support. Also please make tensor key names configurable, make it serializable via state dicts, and let me pass plain keyword args in addition to the usual structured tensor containers. Oh and a runnable end-to-end example training script for discrete IQL would help a lot, styled like the other examples already in the repo.
