I'm working on cloud-nuke and want to add support for cleaning up AWS Simple Email Service resources, because right now when I run it against a test or sandbox account it silently skips all SES stuff and leaves it behind, which means manual cleanup afterward and that's painful for teams that lean on SES in test envs and run cloud-nuke regularly to keep costs down.

I need it to discover and delete five categories: SES configuration sets (the sending configuration profiles used to track email sending events), SES receipt rule sets (rules that route inbound email to various AWS services), SES receipt filters (IP address allow/deny filters for inbound mail), SES email templates (reusable HTML/text templates for sending), and SES identities (verified email addresses and domains used for sending). Each one should list and delete cleanly.

Also each type needs to plug into the existing filtering system like every other resource does. So name-based regex exclusion everywhere, plus time-based exclusion (filtering out resources created after a given time) where it makes sense. Receipt rule sets and email templates have creation timestamps so those should support the time-based filtering, while configuration sets, receipt filters, and identities are name-based only since they don't carry a usable timestamp.

Oh and the config system needs updating too so users can set include/exclude rules for each of these new SES resource types, consistent with how other resource types get configured today.
