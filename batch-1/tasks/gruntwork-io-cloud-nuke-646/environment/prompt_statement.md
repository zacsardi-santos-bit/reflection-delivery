I'm working with cloud-nuke, that tool that automates deleting AWS resources to keep environments tidy, and I just realized it has zero support for Route 53. When I run a full cleanup, hosted zones, CIDR collections, and traffic policies all get left behind and I end up deleting them by hand, which is annoying and inconsistent with how the tool handles everything else. Those lingering DNS resources cause costs to pile up and cause conflicts when I re-create environments later.

So I want to add support for all three of these Route 53 types so they get discovered and deleted automatically like the rest. Each one should list and delete its resources, and each needs name-based filtering so I can include or exclude specific resources with regular expression patterns, same as the other resource types do. Also the config system needs to recognize these three new categories, each with its own independently configurable entry.

Couple of gotchas: for CIDR collections the cleanup has to remove the associated CIDR blocks first before it can delete the collection itself, otherwise it won't go. And for traffic policies, the delete API needs to know the latest version of the policy, so track that version when listing the policies and then pass it along when deleting them. Want this to bring Route 53 cleanup in line with everything else the tool already handles.
