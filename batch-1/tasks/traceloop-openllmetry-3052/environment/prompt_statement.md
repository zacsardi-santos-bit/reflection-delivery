I'm using the OpenAI Python client's newer Responses API in my application, but I've noticed that none of those calls are showing up in my traces. The existing OpenTelemetry instrumentation for OpenAI only seems to cover the older chat completions endpoint — when I use the Responses API to send a message or retrieve a response, no spans are created at all.

I need the instrumentation to cover the Responses API the same way it covers the other endpoints. Specifically, it should create a span for each API call that includes the model name from both the request and the response, the input prompt content and role (handling both plain string inputs and structured message lists), and the output text. For multi-message conversation inputs, each message in the list should be recorded with its index, role, and content. When tool definitions are included in the request, the function names, descriptions, and parameter schemas should be captured; and when the model responds with a tool call, the call name, arguments, and identifier should be recorded on the span along with the overall response identifier.
