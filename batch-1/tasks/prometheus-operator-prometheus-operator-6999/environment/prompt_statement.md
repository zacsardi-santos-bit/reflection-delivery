I'm working on the prometheus-operator and want to add support for routing Telegram alert notifications to a specific group topic (thread) instead of always dumping everything into the main group chat. Telegram lets you organize a group's messages into topics, and folks running large environments use those to split alerts by service or team or severity, so right now there's no way to target the relevant thread and it all lands in the general chat which makes separating concerns painful.

What I need is an optional group topic ID field on the Telegram receiver config so alerts can go to a specific thread. The catch is this only exists in newer Alertmanager versions, so when the operator is pointed at an older Alertmanager and the config still carries a topic ID, I want the field quietly dropped with a warning rather than a hard error. Backward compatibility matters, older deployments should keep working fine.
