I'm working on Apache Calcite's PostgreSQL-compatible SQL dialect and I need to add comprehensive support for timestamp-to-string formatting. Right now the dialect supports only a handful of format tokens, but PostgreSQL has a rich set of them and I need Calcite to produce the same output that PostgreSQL would.

Specifically, I need to implement a formatter that handles all of the following categories of format patterns: 12-hour and 24-hour clock hours, minutes, seconds, seconds past midnight, milliseconds, microseconds, and fractional seconds at 1 through 6 digit precision; AM/PM indicators in uppercase, lowercase, dot-separated uppercase, and dot-separated lowercase variants; era indicators (before/after the common era) in the same case and dot styles; calendar year digits at 1 through 4 digits and as a comma-formatted four-digit form; ISO week-year at 1 through 4 digits; full and abbreviated month names and day-of-week names in uppercase, title case, and lowercase, with an option to translate to the JVM default locale; numeric month, day-of-month, day-of-year (calendar and ISO), day-of-week (both standard and ISO-numbered), week-of-month, week-of-year (calendar and ISO), century, Julian day, and quarter; and Roman numeral months in upper and lowercase.

The formatter also needs to support two modifiers: a fill-mode prefix that suppresses leading zeros on numeric outputs, and uppercase/lowercase ordinal suffixes that append the correct English ordinal (first, second, third, etc.) after any numeric value. These modifiers can be combined — fill mode plus ordinal suffix should produce an unpadded number with the suffix attached.

For text-based patterns like full month names and day-of-week names, the default output should always be in English regardless of the JVM locale. Only when the translation modifier prefix is present should the output reflect the JVM locale. Full day-of-week names should be padded to a consistent width using trailing spaces.

The formatter should be invokable as a static method that takes a format pattern string and a date-time value and returns the formatted string.
