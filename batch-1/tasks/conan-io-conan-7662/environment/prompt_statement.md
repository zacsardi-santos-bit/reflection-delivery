I'm working on a Conan-based project that uses Meson as its build system. Right now, Conan can generate toolchain configuration files for other build systems but has no support for Meson's native machine file format. I need a way to declare project option values — strings, booleans, integers, and arrays — from within my Conan recipe and have them automatically written to a Meson-compatible native configuration file during the install step, so I can pass it directly to Meson when setting up my build.

The generated file needs to follow the format Meson expects: strings in single quotes, booleans as lowercase unquoted words, integers unquoted, and arrays as bracketed comma-separated lists. It also needs to include a section for built-in Meson options like the build type, with values translated to Meson's expected strings (e.g., a Release build type should appear as the lowercase equivalent).

Additionally, the utility that generates C++ source files for integration testing needs to be enhanced so that compiled binaries report compiler identification at runtime — things like the GCC or Clang major and minor version numbers, the Apple build version on macOS, and whether the binary was compiled for 32-bit or 64-bit x86. This is needed so integration tests can confirm that the correct compiler and architecture settings were actually applied during the build.
