I'm working a lot with xarray datasets that have regularly-spaced coordinate axes, uniform spatial grids, evenly-spaced time steps, that kind of thing, and it bugs me that xarray materializes the whole coordinate array in memory when the entire axis is really just three numbers: where it starts, where it stops, and the spacing. I want a built-in range-based index type living in xarray's indexes module that stores only those three params and generates values lazily like the standard range-style array constructors do.

It should be constructible two ways, a step-based factory (start, stop, step) and a count-based one (start, stop, number of points, with an option to include the endpoint or not), and it should expose start, stop, and step as readable properties. When I slice by integer position with a slice object it should hand back a new dataset still backed by the range index with updated bounds instead of blowing up the array. Label-based selection needs nearest-neighbor lookups working for scalars, arrays, and slice objects. Array-based indexing can just gracefully fall back to a normal in-memory index, that's fine. Also renaming either the coordinate or the dimension has to preserve the range index type, and I want a way to convert it into a regular in-memory index when I need compatibility with existing code.

Two other things while I'm here. The approximate-equality comparison helper doesn't work when I pass it standalone coordinate collection objects, it only handles datasets, data arrays, and variables right now, so please extend it to accept coordinate collections too. And there's an annoying bug where datasets using coordinate-transform-based indexes lose their identity after a rename round-trip (rename coords to temp names, then rename them back), after that the dataset should compare as identical to the original but it doesn't. The memory savings here are real for big uniform grids, and range-aware slicing also avoids the floating-point accumulation errors you get slicing a materialized array, so it's worth doing right.
