I'm working on the PyPI warehouse admin system and I need a way to manually activate an organization's premium membership without dragging it through the normal billing/subscription setup. Some orgs come on board through special arrangements (partnerships, pilots, direct agreements) where the standard payment flow doesn't fit, and right now there's just no path to give them premium access without a subscription. So I want an admin-only mechanism to grant an org a manual activation carrying a seat limit and an expiration date.

Once an org has an active (non-expired) manual activation it should be treated as fully operational, exactly the way an org with an active subscription is, meaning members can be invited and premium features work. If that activation expires the org loses good standing and gets treated as inactive. The seat limit is informational only, so going over it should be visible to admins and members for usage purposes but must never block invitations or revoke good standing.

Admins should be able to add, update, and remove these activations from the organization admin detail page. Removing one has to require typing the organization name back as confirmation so nobody nukes it by accident. All three operations (add, update, remove) should record an audit event on the organization and flash an appropriate success or error message depending on outcome.

On the member management side, if a Company-type organization has no active billing and no active manual activation, then trying to invite a new member should fail with a clear error saying the organization isn't in good standing. This check should not apply to Community-type organizations, which stay in good standing without any billing or activation and should keep working as before.

Oh and the activation form needs validation: the seat limit has to be at least 1, and the expiration date has to be strictly in the future, not today or past. If either field is missing or invalid, show a descriptive error rather than silently accepting it. Company orgs need either an active subscription or an active manual activation to count as in good standing, that's the core rule tying it all together.
