I'm hitting an accessibility bug in the Avatar component in our React Native design system and I want your help fixing it. When an Avatar has no photo and no initials to fall back on, it's supposed to render a person silhouette icon so you don't just see an empty circle. That works fine in regular themes, but in High Contrast mode the icon straight up doesn't show, the Avatar just renders a blank circle, which is rough for the folks who actually rely on High Contrast mode (often users with visual impairments), so it's a real accessibility regression not just a cosmetic thing.

I dug into the rendering and I'm pretty sure the problem is that the fallback icon is going through the generic icon slot, and that slot wraps the SVG element in an extra intermediate view. That wrapper is what breaks it, because it stops the SVG from inheriting the theme's foreground colors, and inheriting foreground color is exactly how High Contrast mode colorizes icons, so with the wrapper in place the icon renders with no visible color at all.

What I want is a dedicated slot just for the fallback icon that renders the SVG element directly with no intermediate wrapper, so the icon can inherit color from the theme's foreground color tokens and show up in every theme including High Contrast just like the regular ones. Oh and while you're in there, the icon's dimensions should be explicit numeric values derived from the component's size token rather than relative percentages, and that new slot should get its color and size styling from the appropriate icon tokens. Basically change how the fallback icon is composed and rendered so the person silhouette is visible everywhere.
