I'm chasing a bug in XGBoost's multi-target tree building, specifically the histogram-based builder for multi-target regression. The invariant I care about is that the learning rate should only scale leaf output values proportionally, it shouldn't touch tree structure at all, so two multi-target trees built from the same data with learning rates in a fixed ratio need identical structure (same features chosen for splits at the same thresholds) with only the leaf values differing by that ratio. This holds fine for single-target trees but it's broken for multi-target. The culprit looks like the weight calculation in the multi-target histogram evaluator, where the leaf weight recalc is getting influenced by the learning rate when it really shouldn't be. Can you fix that so the weights come out learning-rate-independent for structure purposes?

There's a couple related things too. Leaf nodes in multi-target trees are supposed to carry a NaN split condition since leaves don't actually have a split, but right now they aren't initialized to NaN, they just hold whatever garbage was in memory, which messes up comparing or reporting split conditions at leaves. So please init those leaf split conditions to NaN.

Also the multi-target histogram builder has no guard against distributed (column-split) training, which isn't implemented yet, and without a guard it could silently produce wrong results. I want it to immediately raise a fatal error with a clear message when someone tries column-split multi-target training with this builder.

Oh and the test helper that generates random gradient data needs to grow multi-target support. Right now it just takes a row count, I need it to also accept a context and a target count so it can produce gradient matrices shaped for multiple targets, meaning one gradient pair per target per sample.

This matters because right now multi-target histogram models don't respect the learning rate the way they should, which breaks correctness and reproducibility for anything relying on consistent leaf scaling in multi-target regression.
