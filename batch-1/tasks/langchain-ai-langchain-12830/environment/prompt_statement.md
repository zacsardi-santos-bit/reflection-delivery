I also need an async flavor of the streaming so agents drop into async apps via async iteration, plus async versions of the plain run/call methods for the non-streaming async case. And it'd be great to have a little utility that takes all the streamed chunks and merges them into one aggregated result, combining lists and scalars the sensible way (concat the lists, take scalars as they come).

Oh and the existing step-by-step iterator API needs a cleanup. There's this confusing parameter you have to set just to opt into async iteration, I'd rather that get detected automatically and drop the param entirely. While I'm in there, add an option to fold run-tracking metadata into the final output, so when I ask for run info the final result carries a unique run identifier I can use to trace and link runs end to end for debugging.

Net effect I'm after: a streaming interface, async run/call, the chunk-aggregation helper, and those iterator API improvements all wired into the agent executor.
