I'm building out the Python client for our metadata catalog and I need to add machine learning models as a proper resource type. Right now we handle filesets and topics and tables, but there's literally no catalog type for models, so the client can't even load a model-focused catalog from the server, let alone manage anything.

I want a new model catalog type (loadable from a catalog like the others) that exposes a full management API. Then for versions I need listing all the version numbers for a given model, fetching a specific version by its number, fetching one by a human-readable alias, linking a new versioned snapshot to a model with a storage URI (and optional aliases), plus deleting a version either by number or by alias.

I also need response objects for reading back model data and model version data from the server. They've gotta deserialize from JSON and validate that the required stuff is actually present, so things like the version number, the URI, and the audit info, and raise appropriate errors when any of those are missing rather than silently passing.
