So I'm in the PatternFly React templates package and I keep composing the same dropdown and single-select patterns by hand from low-level primitives, which is a ton of boilerplate. I want two new template components plus a small tweak to the existing checkbox select so teams stop rewriting this stuff and stay consistent with the design system.

First, a simple dropdown template. It should let me configure the toggle content, disable the toggle, set a toggle variant style, and give a custom toggle width through an inline style. I also want to pass extra props onto the toggle button and set an accessible label for it. It fires a callback when the toggle opens or closes (passing the new open state as a boolean) and another when any item gets selected. There's a flag to make the toggle full-width, and another to control whether the toggle button regains focus after selection, which it shouldn't by default. Items need to support plain action items, link items rendered as anchors with an href, divider items, disabled items (those don't trigger click handlers), arbitrary extra props spread onto the item element, and a per-item click handler.

Second, a simple single-selection select template. When there's no custom toggle content, the toggle should show the placeholder "Select a value" and default to a 200px toggle button width. Same toggle width and extra toggle props customization as the dropdown. It fires a callback with the event and the selected value when an option is chosen, and a separate open/close callback with a boolean. Disabling the whole thing should keep the menu from opening, oh and individual options should support a disabled state too.

Finally the existing checkbox select template needs a configurable toggle width prop defaulting to 200px (replacing the current hardcoded value) and a way to pass extra props to the toggle button. Also its internal container element shouldn't have that hardcoded identifier attribute anymore.
