I'm working with the PatternFly React templates package and I need a couple of new template components added, plus some updates to an existing one.

First, I'd like a simple dropdown template component. It should support configuring the toggle content, disabling the toggle, setting a toggle variant style, specifying a custom toggle width via an inline style, passing additional props to the toggle button, and providing an accessible label for the toggle. It should fire a callback when the toggle opens or closes (passing the new open state as a boolean) and another callback when any item is selected. There should also be a flag to make the toggle full-width, and another flag to control whether the toggle button regains focus after an item is selected (it should not by default). Items passed to the component should support plain action items, link items (rendered as anchors with an href), divider items, disabled items (which should not trigger click handlers), additional arbitrary props spread onto the item element, and a per-item click handler.

Second, I'd like a simple single-selection select template component. By default, when no custom toggle content is provided, the toggle should display the placeholder text "Select a value", and the toggle button should have a default width of 200px. It should support the same toggle width and extra toggle props customization as the dropdown above. It should fire a callback with the event and the selected value when an option is chosen, and a separate open/close callback with a boolean. Disabling the component should prevent the menu from opening. Individual options should support a disabled state.

Finally, the existing checkbox select template needs two additions: a configurable toggle width prop (defaulting to 200px, replacing the current hardcoded value) and a way to pass extra props to the toggle button. The internal container element of the checkbox select should also no longer have a hardcoded identifier attribute on it.
