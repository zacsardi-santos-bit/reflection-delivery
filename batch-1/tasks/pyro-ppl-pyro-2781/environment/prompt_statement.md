I'm on Pyro's funsor-based contrib backend and I keep hitting a wall: there's no way to do MAP inference over discrete latents. Basically I want the single most probable assignment of all discrete hidden variables given my observations, the Viterbi-decode-a-hidden-Markov-model kind of thing, or exact discrete inference in a graphical model more generally. The backend clearly has the machinery to do efficient exact discrete inference, it's just not exposed anywhere.

What I want is a utility that wraps an already-enumerated model and hands me back a new callable. When I run that callable with my data, I get the model's return values but with every discrete latent site set to its most probable value, and the resulting trace's total log prob should equal the max over all discrete configurations. This should hold up across a bunch of model shapes: a single discrete latent, models with sequential dependencies between discrete vars (think HMM state transitions), plate-vectorized discrete latents, and mixed models that combine sequential and plated structure.

Oh and I also need the hybrid case to work: when a model has both continuous and discrete latents, I want to first draw the continuous ones from a variational guide or an MCMC posterior, condition the model on those samples, then MAP-estimate the discrete latents. In that setup the result trace should carry all the same site names as the original model, and importantly the continuous latent sites shouldn't pick up any spurious dependencies on the discrete enumeration variables.

While I'm at it, there's a bug in the funsor backend's replay handling (over in the effect handler code for the contrib funsor stuff) where it currently skips observed sites during replay. That breaks the internal mechanics this MAP inference relies on, so that needs fixing too so observed sites get replayed properly.
