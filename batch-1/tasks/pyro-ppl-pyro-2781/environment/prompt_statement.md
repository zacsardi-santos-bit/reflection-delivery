I'm using Pyro with the funsor-based contrib backend and I need a way to do MAP inference over discrete latent variables in my models — essentially finding the most probable assignment of all discrete hidden states given the observed data. This is the kind of inference you'd need for decoding the most likely hidden state sequence in a hidden Markov model, and I'd expect it to work for various model structures including sequential dependencies between discrete variables, plate-vectorized discrete latents, and combinations of the two.

Currently the funsor contrib doesn't expose this discrete MAP estimation capability, even though the underlying backend has the computational tools to support efficient exact discrete inference. I'd like to wrap an enumerated model with some utility that returns a new callable, and when I run that callable with my data, I get back the model's return values with all discrete latent sites set to their most probable values. The resulting trace's total log probability should match the maximum over all discrete configurations.

I also need this to work in a hybrid inference setting: when my model has both continuous and discrete latents, I want to first sample the continuous latents from a variational guide or MCMC posterior, condition the model on those samples, and then MAP-estimate the discrete latents. In this scenario, the result trace should have all the same site names as the original model, and the continuous latent sites should not pick up any spurious dependencies on the discrete enumeration variables.

There also seems to be a bug in the funsor backend's replay handling — it currently skips observed sites during replay, which breaks the internal mechanics needed for this kind of inference. That will need to be fixed as well.
