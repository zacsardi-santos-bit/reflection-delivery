We're using Cloud Custodian to keep our AWS estate in line, tagging enforcement, network placement audits, cleanup of stale stuff, the usual, and I just hit a wall: there's zero support for SageMaker HyperPod clusters. We've got policies covering notebooks, models, endpoints, domains, but our HyperPod clusters are totally invisible to the policy engine, which is a real blind spot now that folks are leaning on that compute service more.

I want a new resource type added to the SageMaker module (see `@c7n/resources/sagemaker.py`) so we can target these clusters as a first-class thing in policies. It needs to list all clusters and pull full details for each one. On the filtering side I want to match on tags including detecting absent tags, filter by name and attributes, and filter by network config, specifically which subnets and which security groups a cluster is attached to. For actions I need to apply tags, remove tags, and delete clusters that don't meet our standards. Oh and the delete action has to be safe if the cluster's already gone by the time it runs, so it shouldn't blow up when the thing no longer exists.

Also make sure it's registered properly in the resource map so the framework actually recognizes it, and the metadata validation checks (the ones that expect a CloudFormation mapping) need to account for the fact that this resource type doesn't have one, so they don't false-flag it.
