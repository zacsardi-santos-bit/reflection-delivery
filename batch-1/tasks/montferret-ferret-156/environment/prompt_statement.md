I'm working with the ferret datetime standard library and noticed that while I can extract the year, month, and day from a date-time value, there's no way to get the hour, minute, or second. I'd like to add three new functions to the datetime package that each extract one of these time-of-day components and return it as an integer. Each function should take exactly one date-time argument and return the corresponding component — calling it with the wrong number of arguments should produce an error. These new functions should also be registered in the datetime library so they're accessible by name when scripts call them.
