I'm working on improving the type inference system so that function and method return types are inferred from the function body when no explicit annotation is given. Right now, unannotated functions fall back to an indeterminate return type, which means that the floating promise lint rule can't catch patterns like an object method that returns an asynchronous value without an explicit return type declaration. I'd like the system to infer the correct return type from what the function actually returns — no return value for functions that don't return anything, the appropriate type for single-return functions, and a deduplicated union type for functions with multiple return paths. With this in place, the floating promise rule should be able to flag calls to unannotated object methods whose inferred return type is an asynchronous value, just like it does for explicitly annotated ones.
