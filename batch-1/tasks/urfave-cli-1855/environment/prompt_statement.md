I'm using this Go CLI framework and I want to be able to dump an entire command definition out as JSON so I can auto-generate docs and feed my CLI schema into other tooling. Right now there's just no way to serialize a command tree, which is annoying because I've got no machine-readable snapshot of my app's structure to introspect or share across systems.

What I want is for a command to be JSON-serializable so that calling the standard JSON marshaling function on any command gives me a faithful, complete picture of it. That means its name, aliases, usage text, description, version, categories, and behavioral settings all come through, plus all the nested subcommands recursively. Every flag needs its full metadata too, so name, aliases, usage, default value, whether it's hidden, required, persistent, takes a file argument, and whatever type-specific config it carries. Argument definitions should show up as well (integer args for instance) with their name, current value, usage text, occurrence limits (the min/max stuff), and their type-specific config.

Oh and authors, those should work either as a plain string or as a structured object with name and address, so both forms need to marshal cleanly. Also one thing that matters to me, empty or unset collections should serialize as null, not as empty arrays, so the output stays consistent. Basically I just want `json.Marshal` on a command to give me the whole thing.
