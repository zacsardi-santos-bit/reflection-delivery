I'm working on a Kubernetes ingress controller that provisions Application Load Balancers on AWS. Right now the controller always pools ingresses together onto shared load balancers to minimize the number of ALBs used. I need to add support for an ingress-level annotation that lets users opt out of this sharing behavior and request a dedicated load balancer for a specific ingress.

The internal ingress representation needs to carry a boolean flag tracking whether sharing is enabled or disabled for that ingress. This flag should default to true (sharing allowed) when the annotation is absent. When the annotation is explicitly set to disable sharing, the flag should be false. The conversion between the Kubernetes ingress resource format and the internal representation must correctly read and write this annotation in both directions, preserving the value across a roundtrip conversion.
