I'm cleaning up the numeric input editor widget in our content editor and the big annoyance is that a bunch of config options are stuffed behind a "Toggle options" link. Content authors have to click that to reveal advanced settings like how unsimplified answers get treated and whether answer formats are strictly required, and it's just cumbersome and hard to discover. I want all the settings visible directly, no toggle, no expand/collapse, so kill that "Toggle options" control entirely and always show everything.

The other thing is the controls are an inconsistent mess. Width options are standalone buttons right now, while alignment and coefficient are checkboxes, which is weird. I want to reorganize the mutually exclusive stuff into labeled groups of radio buttons. Specifically width options, alignment, number style, answer format strictness, and unsimplified answer handling should each become its own labeled radio group. Each group needs a clear accessible name (a meaningful group label) so screen readers can tell users what the group actually controls, that's the accessibility win here. The answer format type checkboxes should stay checkboxes, but they also need to be directly accessible without toggling like everything else.

Oh and one small thing while I'm in there: the accessible label for the text input used for the aria label field should be lowercased, all lowercase letters.

Authors use this editor constantly so hiding options slows their workflow and makes the UI unpredictable, and the better grouping with clear labels makes the whole thing more usable for folks on assistive tech too.
