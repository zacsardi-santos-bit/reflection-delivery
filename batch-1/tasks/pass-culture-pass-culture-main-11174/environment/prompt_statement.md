I need to add a new section to our back-office administration interface for managing offer price limitation rules — the rules that control how much the price of an offer in a given subcategory can vary. Right now there's no way for our fraud and compliance administrators to see, create, edit, or delete these rules through the back-office UI.

The new section should be protected so that only administrators with the appropriate fraud management permission can access it. It should show a table listing all existing rules with their category, subcategory, and the allowed percentage variation. Administrators should be able to filter the list by category or subcategory. They should be able to create a new rule by picking a subcategory and entering a percentage, with the system rejecting any attempt to create a duplicate rule for a subcategory that already has one. They should also be able to edit the percentage on an existing rule (with validation to reject unreasonably large values) and delete rules they no longer need, with clear success or error messaging for each action.
