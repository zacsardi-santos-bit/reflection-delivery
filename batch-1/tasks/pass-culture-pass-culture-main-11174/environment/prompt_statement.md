We need a back-office admin section for managing offer price limitation rules, the ones that cap how much an offer's price can vary within a given subcategory. Right now our fraud and compliance folks have no way to view, create, edit, or delete these through the back-office UI and I want to bring this in line with the other fraud tools we already have in the admin panel.

The whole section should be gated behind the fraud management permission, so only admins with that permission can even reach it. Landing on it should show a table listing every existing rule with its ID, the category and subcategory it applies to, and the allowed price variation percentage. I also want admins to be able to filter that list by category or by subcategory so it's not a wall of rows.

For creating, an admin picks a subcategory and types in a percentage. If a rule already exists for that subcategory the create has to fail with a clear error message and definitely no duplicate gets written. Editing is just changing the percentage on an existing rule, and I need validation there too so an unreasonably large value gets rejected and the rule stays unchanged rather than saving garbage. Deleting removes a rule permanently. Oh and each of these actions (create, edit, delete) needs its own clear success or error messaging so the admin knows what happened, both the happy path and the failure path.
