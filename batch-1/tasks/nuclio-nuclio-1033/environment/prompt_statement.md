I'm working on the nuclio platform and need to add support for a "never build" deployment mode. Right now, every time I deploy a function, it always rebuilds the image from source — but in many cases I just want to redeploy an existing function without triggering a rebuild. I need a build mode that tells the platform to skip building and reuse the previously built image instead.

There are two scenarios to handle. First, if someone tries to deploy a completely new function using this "skip build" mode, the platform should reject it with an error since there's no existing image to reuse, and the function should not be stored at all. Second, if an existing function is redeployed with this mode, it should proceed using the existing image without rebuilding — and importantly, the timestamp recording when the function was last built should stay the same (since no new build happened). After any deployment, the build mode setting should be cleared from the stored function configuration so it doesn't persist unintentionally.

I also need to extend the test suite helpers to support two new deployment scenarios: one where a deployment is expected to fail with an error, and another that performs two sequential deployments of the same function with separate post-deployment checks.
