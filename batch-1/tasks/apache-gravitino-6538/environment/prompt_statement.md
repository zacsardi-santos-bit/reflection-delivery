I'm working on the Gravitino CLI and hit a gap while listing table columns. Right now when I dump column metadata I get the name, type, nullability, auto-increment, and comment, but nowhere do I see the default value each column is configured with, and that matters a lot for reading a table's full schema without going straight to the database. I want to add default value display to both the plain CSV output and the formatted table output.

The formatting should depend on the type. Numeric literals should just show as plain numbers, string literals should show their text with empty strings made visually distinct via surrounding single quotes, and function-based defaults (think an auto-populating timestamp) should render in function call notation including any field arguments in square brackets. When there's no default configured, leave the field blank.

While I'm at it I'd like a shared utility class to centralize the formatting logic. It should handle display width calculation for CLI alignment with proper support for wide characters like CJK text that eat two display columns, plus spacing, comment display (returning a placeholder when the comment is null), and the default value formatting. Oh and move the auto-increment display logic in there too, it should only show true/false for integer-compatible column types and stay blank for anything else, since showing false on a non-integer type is misleading.

Last thing, the existing formatted table output for a full table's columns needs the new "Default" column slotted in between the "Type" and "AutoIncrement" columns so both output modes line up.
