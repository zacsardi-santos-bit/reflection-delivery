I'm adding support for the Datatrans payment gateway to Active Merchant. Datatrans is a Swiss payment service provider (used in Switzerland, Greece, and the US) and it's just not there yet, so devs can't route payments through it, and I want it to behave like any other supported gateway.

I need the full lifecycle covered: authorizing a card (sending card details, a reference number, currency, and amount to Datatrans), purchasing which is really just authorize plus auto-settle in a single step via an auto-settle flag on that same authorize endpoint, capturing a previously authorized transaction by settling it against its transaction identifier, refunding (crediting) a settled transaction, and voiding (cancelling) an authorization that hasn't been settled yet. Authorization requests should optionally take billing address info too, so name, street, city, country, phone, postal code, and email.

Security-wise I want transcript scrubbing that masks the sensitive card data out of transaction logs, specifically the card number and the CVV, swapped for a placeholder.

On config, the gateway needs merchant credentials at init, a merchant ID and a password, and it should raise an error if either is missing. It should declare support for Visa, Mastercard, American Express, UnionPay, Diners Club, Discover, JCB, Maestro, and Dankort, and the countries CH, GR, and US, with CHF as the default currency. It should talk to the Datatrans sandbox API with a single authorize endpoint (auto-settle flag flips it to purchase), plus separate settle, credit, and cancel endpoints hit per transaction for capture, refund, and void respectively, and it should support both test and live environments. New gateway code lives under the usual Active Merchant billing gateways path like `@lib/active_merchant/billing/gateways/datatrans.rb`, with proper error handling throughout.
