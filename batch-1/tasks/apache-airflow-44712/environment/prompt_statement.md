I'm working on adding deadline tracking to Apache Airflow. The idea is that a DAG run can be associated with a deadline — a specific point in time by which the run should complete — along with a callback to invoke if the deadline passes. I need a database-backed model that stores this association (which DAG, which run, when the deadline is, and what callback to call with what arguments). The model should support saving a deadline record to the database and reading it back with all its fields intact. It also needs a clear, readable string representation that shows the relevant DAG and run identifiers, the deadline time, and the callback with its parameters (or empty parentheses when no parameters are given).
