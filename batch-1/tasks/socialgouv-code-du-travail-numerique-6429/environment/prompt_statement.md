I'm working on refactoring the home page search component so it handles navigation internally rather than relying on a callback passed in from its parent. Right now, the parent component has to supply a function that gets called when the user submits a search — but this creates tight coupling that I'd like to remove. Instead, the search component should take care of redirecting the user to the search results page on its own when they select a suggestion or submit the form, with the query properly encoded in the URL.

As part of this, the search area should use proper semantic form markup so that submitting works naturally (including via keyboard). The submit button should function as a real form submission trigger. I'd also like to fix the visual styling of the autocomplete suggestion dropdowns — both on the home page and in the site header — where the layering and spacing values currently aren't quite right. Finally, the home page title heading layout has a small issue where the subtitle uses a line break element that should instead just be a space so the text flows correctly inline.
