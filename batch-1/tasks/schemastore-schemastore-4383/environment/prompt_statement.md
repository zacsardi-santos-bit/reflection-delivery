I'm working with the gematik Tiger testing platform and we write YAML configuration files to set up test environments. These files define things like proxy configuration, server entries with health-check URLs and routing rules, and various global settings. Right now, SchemaStore doesn't have a schema for these files, so there's no editor validation or autocompletion when writing them.

I'd like to add a schema to SchemaStore for this configuration format. The schema should be registered so that editors automatically pick it up for files following the standard Tiger configuration naming convention. It needs to handle the main configuration sections — proxy settings, a map of named server entries each with their own type, port, health-check, and routing sub-configuration — while still allowing other top-level keys used by various Tiger plugins and extensions without flagging them as errors.
