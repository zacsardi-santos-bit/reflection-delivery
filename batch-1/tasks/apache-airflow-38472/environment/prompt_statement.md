I noticed that task instances and task/operator definitions currently include a field for assigning a specific executor to individual tasks — but this feature was never actually implemented or supported. The field shows up in task instance data returned by the model layer, in serialized DAG and task definitions, and in the web UI task instance views. Since the capability was never completed, I'd like this field removed from all of those data structures to avoid confusing users who might try to rely on it.
