I'm building out a trace sampling processor and I'm stuck because there's no actual logic yet for deciding whether to keep or drop a trace, so right now it's all or nothing and I can't express any real policy. I want a rule-based engine that lets me say things like "sample traces from this specific HTTP route when they're slow" or "always keep traces that have an error span."

Two kinds of rules to start. First is an endpoint-specific rule that targets a particular service name plus an HTTP route with a latency threshold, so if the trace has a span from the right service and route whose duration goes over the threshold, that trace gets sampled. If the service and route match but the latency is within the threshold, it should fall back to a configurable sampling ratio instead. And if neither the service nor the route match, the rule just isn't applicable at all. Second is a global rule that applies to every trace and samples any trace containing at least one error span, and when no error is found it falls back to a configured sampling percentage.

Each rule should expose an evaluation method that tells me whether the rule matched the trace, whether the primary condition was actually satisfied, and what fallback ratio to apply. The engine itself needs two tiers: endpoint-level rules get evaluated first with higher priority, and global rules act as the fallback only when no endpoint rule matches. Important bit, if any endpoint rule matches the trace (even when its primary condition isn't met) the global rules shouldn't override that result. If any matching rule is satisfied, or a fallback ratio pulls the trace in, the engine returns that it should be sampled.

Oh and I also want a little test utility library so I can build traces with specific service names, span attributes, status codes, and latency values, that way I can test the rules in isolation without dragging in real trace data. The whole point here is letting operators grab the high-value stuff (slow endpoints, error paths) always while sampling just a configurable slice of normal traffic for baseline coverage.
