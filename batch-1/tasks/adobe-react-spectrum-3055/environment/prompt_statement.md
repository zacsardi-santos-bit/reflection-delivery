I'm working on a list component that supports drag-and-drop. Right now, items marked as "disabled" are excluded from drag operations — they don't get the draggable indicator, their data isn't included in the drag payload, and they aren't counted in the accessibility label that tells users how many items are being dragged. This feels wrong: if a user selects several items and drags them, all of the selected items should move together, even if some of them are "disabled" in the interaction sense.

There was also a feature that let you pass in a callback to selectively mark certain items as non-draggable. I'd like that removed — it creates confusing behavior where selected items silently disappear from the drag data.

The desired behavior is that any item in a draggable list can be dragged, regardless of its disabled status. Disabled rows should show the drag handle on hover, press, and keyboard focus, just like any other row. When multiple items are selected and a drag starts, all selected items should be included in the drag data and reported in the drag lifecycle events. The accessibility label on the drag handle should count all selected items, not just the ones that were previously considered draggable.
