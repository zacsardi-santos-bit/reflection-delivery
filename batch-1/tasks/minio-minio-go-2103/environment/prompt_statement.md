I'm hacking on the minio-go client and need three pieces landed. First up, a helper that tells me whether a bucket name is an S3 Express directory bucket. These follow a specific convention where the name ends in a two-part suffix, an availability zone id followed by a fixed marker like `--x-s3`, and the AZ id itself is a short alphanumeric region code plus `-az` plus a single digit, so things like usw2-az1, use1-az5, apne1-az4 are valid. I want it to reject names that look like IP addresses, ones that start with a dot, ones with consecutive dots or consecutive hyphens in the name portion, and anything with a malformed AZ segment. Basically detect real S3 Express buckets programmatically so we can make routing decisions off it since these need different handling than standard buckets.

Second, I want a new generic, type-safe key-value cache package that works straight from its zero value, no constructor call needed. This should replace an older internal ad-hoc cache struct.

Third, a new generic, type-safe singleflight-style package for deduplicating concurrent identical operations. When a bunch of goroutines fire the same op at once, only one actually runs and everyone shares the result. It needs both a synchronous call style and an async channel-based style. Also gotta handle the nasty edge cases right, panics should propagate to all callers, and goroutine exits (runtime.Goexit) shouldn't hang or turn into errors. Oh and I need a way to forget a key so the next caller runs fresh instead of waiting on an in-flight call. Point of both utilities is type safety and killing off the internal one-off implementations so these patterns are reusable across the library.
