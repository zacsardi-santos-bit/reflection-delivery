I'm working on the minio-go client library and need to add a few things. First, I need a utility function that can tell whether a given bucket name is an S3 Express directory bucket. These buckets follow a specific naming convention — they have a particular suffix pattern involving an availability zone identifier — and I need to be able to detect them programmatically. The function should reject names that look like IP addresses, have consecutive dots or hyphens in the name portion, start with a dot, or have a malformed availability zone segment.

Second, I'd like to introduce a new generic, type-safe key-value cache package that can be used directly from its zero value without any constructor call. This would replace an older internal cache structure.

Third, I need a new generic, type-safe package for deduplicating concurrent identical operations. When multiple goroutines try to execute the same operation simultaneously, only one should actually run and the result should be shared with all the others. It should support both a synchronous call style and an asynchronous channel-based style. It also needs to correctly handle edge cases like panics (propagating them to all callers) and goroutine exits (not hanging or returning errors). There should also be a way to "forget" a key so that the next caller runs the operation fresh rather than waiting for an existing in-flight call.
