I'm working on the cluster management tooling that installs provider components into a Kubernetes cluster. When a user specifies a target namespace, the tool is supposed to rewrite all namespace references in the provider manifests so that everything lands in the correct namespace. The basic rewriting works fine for ordinary objects, but it doesn't handle admission webhook configurations or custom resource definitions that contain embedded namespace references in their webhook client configurations. It also doesn't rewrite the namespace portion of cert-manager certificate injection annotations on those objects.

This means providers that use webhooks get installed with stale namespace references, so the webhooks point at the wrong namespace and break. I need the namespace-fixing logic to also handle these webhook-related objects — updating the service namespace inside webhook client configs and fixing the namespace in cert-manager annotation values. The function that does this work should also return an error rather than silently succeeding when something goes wrong.
