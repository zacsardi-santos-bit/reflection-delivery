I'm poking around the kustomize filesystem abstraction and there's a couple of small primitives missing that I keep wanting when I'm juggling path strings. First thing, I want an exported helper in the `@api/filesys` package that takes a path string and strips any trailing path separators off it. So something like "foo/bar///" comes back as "foo/bar", and if the thing is nothing but separators it should collapse to an empty string, oh and if there aren't any trailing separators at all then just hand it back unchanged. Right now there's no centralized way to do this so people either reimplement it inline or don't bother, which is annoying.

Second, I want an exported package-level constant that represents the current directory, just the single dot ("."), living in that same filesys package so callers all over the codebase can reference it instead of each defining their own local version of it. It's silly having that token redefined ad hoc in a bunch of spots.

Basically I want both of these to live in the api/filesys package so path manipulation stays consistent and reusable, and we kill off the duplicate scattered implementations. Nothing fancy, just the two additions.
