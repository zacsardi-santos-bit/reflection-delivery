I'm cleaning up the bookmark saving flow in our Android app and hit a few gaps. I want those commands updated so they carry the parent folder alongside the saved site, so the edit dialog actually knows which folder the bookmark lives in and can show the current location or let the user change it in the same flow. Right now returning to the picker after creating a folder elsewhere doesn't refresh the list, which is annoying, so this inline create path needs to work.

Oh and the bookmarks repository is missing a lookup to fetch a bookmark folder by its own id and return the full folder details. I need that added to both the repository interface and its concrete implementation so the view model can grab folder details when displaying or editing a saved site. These little gaps make organizing bookmarks way more cumbersome than it should be, so I want all three tied together.
