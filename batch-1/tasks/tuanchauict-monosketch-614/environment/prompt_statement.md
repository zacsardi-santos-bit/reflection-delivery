I'm porting MonoSketch to Svelte/TypeScript and I need a group shape type, basically a container that holds an ordered collection of child shapes and manages them as one logical unit. Right now there's nothing that lets me group shapes together, control stacking order, or enforce ownership, so I want to build that out.

A fresh group should start empty. I need to add shapes at a specific position: at the end by default, at the beginning, or after some particular shape that's already in the group. Ownership matters here, so if a shape already belongs to a different group, trying to add it somewhere else should just be silently rejected (no error, nothing happens). When a shape does get added successfully the group takes ownership of it, meaning the shape's parent reference gets updated automatically. And adding a shape that's already in this group should be a no-op. I also want removal, plus reordering, so I can move a shape up one step or down one step in the stacking order, or jump it all the way to the top or all the way to the bottom.

Separately, the rectangle shape over in the rectangle module is annoying to work with. It's not exported so I can't use it from other modules, and its constructor demands an explicit id even when I don't care about one. So I want to make the rectangle publicly accessible, let me construct it with just a bounding rectangle (no explicit identifier required), and add a convenient factory method that builds one from a plain object where both the identifier and the parent reference are optional.

This stuff is foundational for a drawing tool, without groups you can't treat a bunch of shapes as a single composite thing or do layering and hierarchy on the canvas, so it needs to actually enforce these rules.
