I'm working on cloud-nuke and I need to add support for cleaning up S3 access points. Right now the tool handles S3 buckets just fine, but it has no awareness of the three access point variants that AWS supports: standard access points, object lambda access points, and multi-region access points. When I run a full cleanup of a test environment, all three types of access points get left behind.

I'd like cloud-nuke to be able to discover and delete each of these three access point types, following the same pattern used by other supported resources. For standard and object lambda access points, name-based filtering (regex exclusion) should work. For multi-region access points, both name-based and time-based filtering should be supported — specifically, the ability to exclude access points created after a certain point in time. The configuration system should also recognize each of these as distinct resource types so users can apply independent filtering rules to each.
