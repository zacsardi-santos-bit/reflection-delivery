So I'm working on our Navigator sidebar, the one with collapsible groups, and I hit a gap. The individual nav items already support an active/selected state but the group header component doesn't have any way to mark a group as currently active. I want to add that. The idea is when a user is viewing a section that belongs to a group, we can highlight that group's header so it's obvious which group corresponds to what they're looking at right now. Right now every group looks identical no matter whether its content is being displayed, which is confusing for orientation.

So what I need is for the group header component to accept a boolean prop indicating whether it's active. When it's active, render the header with a distinct highlighted visual style that clearly stands apart from the other groups. When it's not active, keep the default appearance, and that default needs to still carry the normal hover and focus-visible interaction states so nothing regresses there. Oh and the header can take extra content meant to sit on the right side, so make sure that content actually renders when it's passed in, active or not.

This is really about letting navigation communicate state to users. Without an active indicator there's no way for the app to signal which group matches the current section, and selected state matters a lot for orientation in apps that use this navigator.
