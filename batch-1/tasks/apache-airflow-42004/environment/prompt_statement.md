I'm working on adding a simple, built-in authentication manager to Apache Airflow that doesn't require any external identity provider. Right now, setting up authentication for a development or testing environment is unnecessarily complex. I want a lightweight auth manager that can be selected via configuration, auto-generates passwords for declared users, and persists them to a local file.

The auth manager needs to support four roles with a clear hierarchy: a read-only viewer role, a user role with full DAG access, an operator role with access to operational resources (connections, configuration, pools, etc.), and an admin role with full access. Viewers and above should be able to access UI views once logged in, but unauthenticated users should be denied everything.

There also needs to be a user model that stores a username and role and exposes them via standard interface methods. The web interface should have a login page showing a "Sign in" heading, a short instruction line about entering login credentials, and labeled fields for username and password. Logging out should clear the session and redirect to the login page. Submitting credentials should redirect to the main dashboard on success or back to the login page with an error flag on failure.
