I'm working with a React form library and I need a way to listen to form state changes from outside of a React component. Right now the only way to react to things like a field becoming dirty or values changing is through hooks inside a component, which always causes re-renders. I'd like to be able to create a form control independently, set up a callback subscription that fires whenever certain parts of the form state change, and optionally scope that subscription to a specific field so I only hear about changes to that field. The callback should get the full current form state so I can act on it. Ideally, when this same form control is later used inside a React component, the component should only re-render for state it explicitly subscribes to — the external callback shouldn't force React re-renders on its own.
