I'm trying to make the text input autocomplete suggestions feature more accessible for screen reader users. Right now, when I render the component with a list of suggestions, the rendered markup has no semantic roles or states that assistive technologies can use to understand what's happening. The input itself doesn't announce that it's an autocomplete field, the dropdown showing suggestions isn't marked as a list of options, and none of the individual suggestion items carry any role or selection indicator.

I'd like the input to properly identify itself as an autocomplete combobox and expose whether the suggestion list is open or closed. The suggestions container should be identified as a listbox and have a stable identifier linked to the input. Each suggestion item should be identified as a selectable option, have its own unique identifier based on its position in the list, and expose whether it is currently the selected value. These changes should apply when the component is given an id and has suggestions provided.
