I'm working on the router's control plane polling component and need to add jitter support to prevent multiple router instances from all hitting the configuration server at exactly the same time. Right now the poller just takes a fixed interval, but I want to be able to pass in a maximum jitter value so each instance can add a small random delay before each poll cycle.

The polling component should accept both the poll interval and a maximum jitter duration when it's created. If either value is invalid — like a zero or negative interval, or a negative jitter — the component should panic immediately at creation time so misconfiguration is obvious at startup. A jitter maximum of zero should be perfectly valid (it means no jitter). The underlying random delay generator should follow the same rules: panic on negative input, return zero for a zero maximum, and return a random value within the allowed range for positive inputs.
