I'm working on Cypress and want to add a heads-up for folks still on 32-bit Windows. Right now if someone opens a project on one of those machines there's zero indication that the platform is on its way out, so they'll just get blindsided when a future release drops support. Related context is over in cypress-io/cypress#18094 if you want the background.

What I want is for the project creation flow to check the environment during init and, if it detects it's running on 32-bit Windows, fire off a warning. The key thing is it has to check both the platform and the CPU architecture, so basically the OS is Windows and the arch reports as 32-bit (ia32), and only when both of those line up should the warning trigger. There's already a warning callback passed through the options into the create step, so use that existing mechanism rather than inventing a new one. The message that goes through that callback should make it clear the user is on a 32-bit build so they know what's being deprecated and can plan a move to 64-bit before it stops working.

Important that this stays narrow, oh and it should only fire for 32-bit Windows. Other platforms and 64-bit Windows shouldn't see the warning at all.
