I'm working on zero-knowledge proof functionality in Sway and I need the standard library to provide proper types for elliptic curve cryptography. Right now there's no standard way to represent a two-dimensional elliptic curve point or a scalar value, which makes it impossible to cleanly use the elliptic curve operations the VM supports.

I need a curve point type and a scalar type added to the standard library's crypto module. The curve point type should let me construct a point from pairs of 256-bit integers (in various forms — tuples, arrays, raw byte arrays), retrieve the x and y coordinates as byte sequences, check whether the point is the zero/identity element, compare two points for equality, and convert back to the original numeric representations. The scalar type should similarly support construction from 256-bit integers and byte arrays, expose its bytes, check for zero, and convert back.

Beyond the types themselves, I need three functions that operate on them: one that adds two curve points together, one that multiplies a point by a scalar, and one that takes a list of point pairs and evaluates whether their bilinear pairing relationship holds. All three should revert rather than silently produce wrong results when given inputs that aren't valid curve points. The pairing check should return a boolean — true if the pairing check passes, false if it doesn't — while the add and multiply operations should return the resulting point.
