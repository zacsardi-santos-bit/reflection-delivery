Right now when that mode is enabled the functionality is either missing or getting pulled from outside, and I want a first-class internal module living in the Dask codebase so it's easier to maintain and iterate on.

And the results need to match what I'd get running the equivalent op on the computed underlying array data, so the objects have to be computable and give correct numerical output.
