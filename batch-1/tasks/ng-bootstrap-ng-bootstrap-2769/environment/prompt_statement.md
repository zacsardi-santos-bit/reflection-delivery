The tool currently uses the old CommonJS module format, but we've moved to TypeScript everywhere else in the project, so this is now inconsistent. I'd like to convert the utility to a TypeScript file and expose its main function as a named export so it can be imported using standard TypeScript module import syntax, rather than being loaded with the CommonJS require approach.

The only change from the user's perspective is that the module can now be imported using a named import rather than a CommonJS require call.
