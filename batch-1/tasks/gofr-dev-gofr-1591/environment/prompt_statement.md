I'm working on the SurrealDB integration in our Go framework and I've hit a few gaps that need filling. Right now the client only supports querying existing data, but there's no way to insert new records into a table or delete records by their identifier. I also need to be able to manage the database schema at the administrative level — creating and removing namespaces and databases programmatically through the client. All of these operations should fail gracefully with a clear error if the connection hasn't been established yet.

On top of that, the framework has a migration system that other databases (like MongoDB, Cassandra, and ArangoDB) already support, but SurrealDB has no integration with it. I need SurrealDB to be a first-class citizen in the migration system so that developers can run versioned schema changes against it. This means implementing the full migration lifecycle: setting up the migration tracking table, querying the last applied migration version, committing a completed migration (recording version, method, start time, and duration), and beginning a transaction with the appropriate log output.
