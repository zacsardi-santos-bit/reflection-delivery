I need to create a Pants plugin that automatically populates common metadata for StackStorm's Python distributions during wheel builds. Right now, every `python_distribution()` target would need to manually specify the same author, license, project URLs, and other metadata over and over again. I want the plugin to automatically set standard values like `author="StackStorm"`, extract the version from a `__version__` variable in a specified file, and pick up README.rst as the long description if it exists. The plugin should also add standard classifiers for development status, audience, license, and Python versions, while still allowing individual packages to add their own custom classifiers.
