I work with image and array filtering a lot, and I often need to apply custom reduction functions over sliding windows of an array. The existing generic filter in the image processing library works great, but it calls my function once per output element, which is incredibly slow for large arrays when the function I want to apply already supports batched inputs natively.

I'd like a new filter function that passes all the sliding windows to my callable at once (or in memory-controlled batches), so that vectorized operations like computing the mean or sum over windows can run much faster. The function should behave identically to the existing generic filter for standard boundary modes (reflect, nearest, mirror, wrap, constant), but also support a "valid" mode that returns only the elements where the window fits entirely inside the array — no padding.

It would also be helpful to have a parameter that limits how much memory is used for the batch of windows at one time, so I can use this on large arrays without running out of memory. If the memory limit is set too low to process even the smallest possible batch, it should raise a clear error. The function should support all the usual options: custom footprints, axis selection, and output arrays.
