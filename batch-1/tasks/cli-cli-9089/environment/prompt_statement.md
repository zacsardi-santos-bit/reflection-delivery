I'm cleaning up the git credential management code in the GitHub CLI's auth shared package because it's all crammed together right now, detecting which credential helper is active, writing our own helper into git config, and updating stored credentials all live in one place and it's really hard to test any of it independently. I want to pull this into a dedicated sub-package with three focused types.

First, a type that represents a configured credential helper and can tell whether the helper command belongs to our tool or to some third party. It needs to distinguish our tool's helper command from others, including tricky edge cases like commands that look similar but actually aren't ours, and it's gotta handle Windows-style paths correctly too.

Second, a type that reads and writes git credential helper config in global git config for a given hostname, covering both the main hostname and its associated gist hostname. It should handle the case where no credential helpers exist at all, where a global third-party helper is already set, and where a host-specific third-party helper is already set.

Third, a type that stores and replaces credentials using the git credential system. When updating, it should erase (eject) the old credentials before storing the new ones so a subsequent credential lookup returns the updated values, basically atomic replace.

All three need to be independently testable against an isolated git config. Then update the rest of the auth package to depend on these instead of the old mixed impl. The existing credential flow type needs its fields reorganized to use these new types, and a previously internal method should be promoted to a proper public method with a cleaner name. Also the setup-git command's options struct needs a field rename to match the updated interface, which should now expose just the single method needed to register our tool as the credential helper for a hostname. Registering has to work both when no other helpers exist and when pre-existing helpers are already configured.
