I'm deep in the Kong Kubernetes Ingress Controller and hitting two related problems with how we manage admin API clients that I'd like sorted out together.

First, endpoint discovery is too aggressive. Right now we drop endpoints whenever they're marked not-ready, but that's the wrong signal. An endpoint that's temporarily not responding but isn't being torn down is still a perfectly good candidate. The thing I actually want to exclude on is the terminating flag, not readiness. So an endpoint that's ready but terminating should be excluded, and one that's not-ready but not-terminating should be included. As it stands the non-ready non-terminating ones get incorrectly dropped and the ready-but-terminating ones can sneak in, which is backwards.

Second, the manager has no way to deal with clients we've discovered but can't reach yet. When the controller learns about new admin API addresses, some might not be reachable right away, and today those just get discarded at creation time with no retry. I want the manager to keep a pending set of not-yet-reachable clients alongside the ready set of active ones, and periodically check both, promoting pending clients that have become reachable and demoting ready clients that have gone unreachable. Please pull this readiness-checking concern out into its own component so it can be tested and swapped independently.

Also the manager should expose an explicit method to kick off its processing loop rather than starting implicitly, and it should let me configure the interval at which the periodic readiness reconciliation runs. Oh and one more thing, creating a manager with no initial clients should fail with a clear, descriptive error saying at least one initial client is required.

Why this matters: without it the controller can fail to connect to healthy admin API endpoints that are just briefly not-ready, and it's got no path to recover connections to endpoints that were unreachable at startup but come online later. That's rough in dynamic environments where admin API pods restart or roll out gradually.
