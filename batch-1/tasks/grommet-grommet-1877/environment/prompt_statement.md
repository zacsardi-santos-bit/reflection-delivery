I'm working with the Box layout component in our UI library and I keep hitting the same annoying thing: there's no built-in way to space out child elements. Right now if I want gaps between children in a row or column I've gotta manually slap margins or padding on every single child, which is repetitive and honestly drifts away from the design system's spacing scale since I end up hardcoding values.

What I want is a new spacing property on Box itself where I can just declare how much space goes between its children. It should pull from the same size tokens we use everywhere else in the design system, so extra small, small, medium, large, and extra large. And the important bit: the spacing should only land between adjacent children, not before the first one and not after the last one, so no stray leading or trailing gap.

Oh and it needs to be documented too, the available values and a description of what the property does should show up in the component's README so other devs can actually discover it exists. Btw the whole point is keeping layout intent readable in one place on the container instead of boilerplate per-child styling, and making sure spacing stays aligned with our standard scale.
