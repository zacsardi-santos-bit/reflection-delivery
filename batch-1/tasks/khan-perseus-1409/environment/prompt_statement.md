I'm working with a test builder utility for interactive graph questions, and the API has become inconsistent and hard to work with as we've added more graph types. Right now, some methods accept a plain array of coordinates as their argument while others use a completely different convention, making it unclear whether you're specifying where the graph starts or what the correct answer is. I'd like to refactor these methods so they each accept a named options object with clearly labeled fields for correct-answer coordinates and starting positions — that way it's obvious at a glance which is which.

We're also missing builder support for a couple of graph types (specifically point graphs and angle graphs), so those need to be added. It would also be helpful to have methods for setting the question's text content and for attaching a background image with its dimensions and optional positioning properties.

On top of that, the default color used for decorative locked figures (non-interactive reference shapes drawn on the graph) should be changed from green to a neutral dark gray, and the endpoint markers on locked decorative lines should be hidden by default. The default correct-answer coordinates for each graph type should also be updated to represent more centered, sensible positions on the graph canvas rather than the current extreme edge positions.
