So I'm cleaning up the test builder utility we use for interactive graph questions, over in the perseus-ish grapher helpers, and the API's gotten messy as we've piled on more graph types. Right now some of the builder methods take a plain positional array of coordinates while others use a totally different convention, so you genuinely can't tell whether you're setting where the graph starts or what the correct answer is supposed to be. I want each graph-type builder method to instead take a named options object with clearly labeled fields, one for the correct-answer coordinates and one for the starting positions (starting layout), so it's obvious at a glance which is which and we stop hitting subtle setup bugs.

Also we're just missing builder support for a couple graph types, specifically point graphs and angle graphs, so add methods for those since they aren't there yet. Oh and I need a way to set the question's content text directly through the builder, plus a method to attach a background image, which should take the URL, its dimensions (width/height), and optional positioning/scale attributes.

Couple more defaults to fix while you're in there: the default color for decorative locked figures (the non-interactive reference points and lines we draw on the graph) is currently green, but design wants a neutral dark gray when nobody's picked a specific color, so switch it. Endpoint markers on locked decorative lines should be hidden by default instead of shown. And the default correct-answer coordinates for each graph type are sitting at extreme edge positions right now, so update them to more centered, sensible spots on the canvas. Test authors set up starting and correct-answer states constantly, so making this consistent matters.
