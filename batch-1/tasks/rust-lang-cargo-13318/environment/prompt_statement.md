I have a project with a git dependency that specifies a particular branch. When I ask cargo for the package ID of that dependency, it gives me back a URL that includes the branch information as a query string parameter. The problem is that when I try to use that package ID directly with the package selection flag to build that specific dependency, cargo fails. I'd expect to be able to take the exact package ID that cargo itself reports and pass it right back in as a package selector without any modification. Is there a fix to make cargo correctly handle package IDs that contain URL query strings when used as package selectors?
