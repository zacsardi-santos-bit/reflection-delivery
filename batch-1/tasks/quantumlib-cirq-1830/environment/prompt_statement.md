When the wrong number of qubit arguments is provided, a clear error message should indicate how many arguments the gate expects vs. how many were given, along with the line number. Same thing for unexpected parameters on a gate that doesn't take any.

I also noticed that some test files have nearly identical code for verifying that QASM output matches what an optional external quantum simulator produces when it is installed. It would be cleaner to extract that into a shared utility in the testing module so it can be reused without duplication.

Ultimately, I want to be able to take a circuit with these standard gates, serialize it to QASM, parse it back, and get a circuit whose unitary matches the original — and optionally cross-verify this against an optional external quantum circuit simulator as well.
