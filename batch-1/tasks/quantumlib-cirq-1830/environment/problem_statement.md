## Description

The QASM import functionality in Cirq does not support many of the standard multi-qubit gates that appear in QASM circuit files. When importing a QASM circuit that uses common two-qubit gates (such as controlled-NOT in either case form, controlled-Z, controlled-Y, SWAP, or controlled-H) or three-qubit gates (such as the Toffoli gate or controlled-SWAP), the parser fails to recognize them and raises an error.

## Expected Behavior

- The QASM importer should recognize and correctly parse common two-qubit gates from the standard QASM library, mapping each to its Cirq equivalent
- The QASM importer should recognize and correctly parse common three-qubit gates (Toffoli and controlled-SWAP), mapping them to their Cirq equivalents
- When these gates are applied to full qubit registers, the parser should broadcast the gate across all register elements, consistent with QASM semantics
- Providing the wrong number of qubit arguments to a multi-qubit gate should produce a clear error indicating the gate's expected argument count, the actual count given, and the line number
- Providing unexpected parameters to a gate that takes none should produce a clear error indicating that no parameters are expected, with the line number
- A circuit containing these newly supported gates should round-trip correctly through QASM: converting to QASM and back should produce a circuit with the same unitary behavior

## Additional: Shared External Simulator Verification Utility

There is currently duplicated code across multiple test files for verifying that QASM output is correctly interpreted by an optional external quantum simulator library (when available). This shared logic should be extracted into a reusable utility function in the testing module so it can be called consistently from multiple places without code duplication.

## Why This Matters

Without support for these standard multi-qubit gates, Cirq cannot import most real-world QASM circuits, since controlled-NOT, SWAP, and Toffoli are among the most commonly used gates in quantum computing. Adding this support allows users to freely import QASM circuits generated by other tools and frameworks.
