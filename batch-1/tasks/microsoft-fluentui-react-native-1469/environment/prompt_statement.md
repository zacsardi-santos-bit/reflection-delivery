I'm hitting a few problems with the experimental Checkbox in Fluent UI React Native and could use a hand fixing all three at once. The big one is render stability: every re-render, even with identical props, spits out brand new style and accessibility objects instead of reusing what it computed last time. This trips render consistency checks and it's a perf problem too since anything downstream that keys off referential equality for change detection sees a fake "change" every pass, worst case it kicks off infinite re-render loops. What I want is that rendering twice with the same props (whether or not I pass a style override) hands me back referentially equal computed style objects both times, and the component just re-renders identically when nothing changed. Passing a style object or custom accessibility actions shouldn't destabilize any of that.

Second thing, related actually, is accessibility actions. When I pass an extra action through props it breaks down instead of merging with the built-in toggle action, and that also causes the instability above. The default toggle action needs to always be there and any additional actions I pass should get appended alongside it, merged in rather than replacing it.

Third, I'm missing some design tokens I need for customization. I want one token controlling the overall size of the checkbox box (the width and height of the box element), one controlling the size of the checkmark indicator inside the box (its width and height), and one for the spacing between the checkbox and the label when the label sits after the box, which should add end-margin spacing to the label so I can dial in how far it is from the box.

So it's the experimental Checkbox component's source that needs the work. Fix the render stability so styles and accessibility props stop getting recreated each pass, fix the custom accessibility action merging so my actions land next to the default toggle, and add those three tokens (box size, checkmark size, label spacing). These together are what's making it hard to use reliably in production, both perf and customization wise.
