I'm building out a MySQL schema migration tool and hit two things I want cleaned up. Right now all the constants and the function type that describe MySQL server capabilities (whether the server supports instant DDL, fast table drops, JSON columns, the various version-gated features, etc.) live inside the core MySQL connection package, which means anything that just wants to check "does this server support X" has to import the whole connection layer. That's way too much coupling. I want those capability constants plus the associated function type pulled out into their own dedicated self-contained sub-package so other code can import them independently without dragging in the full MySQL client, and every existing reference across the codebase needs to get updated to point at the new location.

Second thing, the schema comparison library needs a new public function that decides whether a given ALTER TABLE can run via instant DDL on a server with the given capabilities. It should walk each operation in the alter and only return true if every single op qualifies under instant DDL rules. So adding a column at the end is fine but adding one in the middle isn't, dropping columns depends on virtual vs non-virtual and whether the table uses compressed row format, changing column defaults is ok, and appending values to enum or set columns qualifies except inserting enum values in the middle disqualifies, crossing the storage-size threshold for set columns disqualifies, and changing a column's data type at the same time as its default is also a no. Basically true only when the whole statement is instant-eligible.

Oh and the schema diff type should also get a method that checks whether an entire collection of diffs can be applied instantaneously, where trivially-instant stuff like table creation or view changes always counts as qualifying. The point of all this is migration tooling needs to know upfront if a change is instant or if it'll trigger a full table rebuild, without duplicating logic or eating the full import weight of the MySQL package.
