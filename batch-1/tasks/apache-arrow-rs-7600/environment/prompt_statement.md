I'm trying to write an encrypted Parquet file with a plaintext footer using key metadata identifiers, so that the file can later be decrypted using a key retriever that looks up keys by name. The reading side already supports key retrievers, but the writing side doesn't seem to have a way to attach a key identifier to the footer encryption key or to a column's encryption key. I need to be able to specify, when building the encryption properties, both the actual key bytes and a metadata identifier for each key — the footer key and each column key — in a single step. Once written, the file should be readable by a key retriever that resolves the metadata identifiers to the correct key bytes, and reading with an incorrect key should produce an informative footer signature verification failure error.
