I'm working on the memory-mapped file library in the Qdrant codebase and I need to add a read-only typed slice abstraction. Right now the library has a typed wrapper for writable memory maps that lets you treat a mmap as a slice of some element type, but there's no equivalent for read-only maps. Some parts of the codebase need to hold both a writable and a read-only view over the same underlying file, and without the read-only typed slice type the whole library fails to compile.

What I need is a new module in the memory library that exposes a read-only typed slice type, similar in spirit to the existing writable typed slice. When you hand it a read-only memory-mapped file, it should let you treat the contents as a slice of any fixed-size element type, with the length automatically derived from the file size and the size of the element type. The conversion should succeed when the file size is a proper multiple of the element size, and return an error otherwise.
