I'm working with the staking precompile in Sei chain and I need to add support for creating and editing validators through the EVM. Right now the precompile only lets you delegate, redelegate, and undelegate tokens — but there's no way to register a new validator or update an existing validator's settings from the EVM side.

I'd like to add two new operations to the staking precompile. The first should let a caller create a new validator by providing a consensus public key in hex format, a display name, commission rate settings, a minimum self-delegation amount, and an attached funding value for the initial self-delegation. The second should let an existing validator update its display name, commission rate, and minimum self-delegation amount — with the ability to skip updating the commission rate or minimum self-delegation by passing an empty string or zero respectively.

Both operations need proper input validation with clear error messages — things like invalid hex for the public key, missing funding value, non-parseable commission rates, zero self-delegation, the validator not existing when trying to edit, and the caller's address not being linked to a native chain address. On the success path, the validator should be queryable with the correct moniker, and an edit should only change the fields that were explicitly provided while leaving everything else (operator address, consensus key, unchanged commission rate or self-delegation) intact.
