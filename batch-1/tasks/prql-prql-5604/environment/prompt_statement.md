I'm trying to use PRQL with Snowflake as the target SQL dialect, but interval and duration arithmetic doesn't compile correctly. Other SQL targets seem to handle intervals in their own format, but Snowflake's specific interval quoting requirement isn't being handled. It would be great if duration arithmetic in PRQL could be compiled to the correct Snowflake interval expression format so that date calculations work properly when targeting Snowflake.
