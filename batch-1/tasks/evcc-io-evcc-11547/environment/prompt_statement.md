We've been leaning on `github.com/golang/mock` for our Go test mocks and it's been archived for a while now, the community moved over to the maintained fork at `go.uber.org/mock` and I want us off the dead dependency before it starts blocking ecosystem updates. Basically I want the whole codebase migrated to the uber fork.

So this means every test file that imports the old mock framework (the `gomock` package plus anything pulling from the old path) needs to point at the new location instead, and all our auto-generated mock files, the ones produced by mockgen, need regenerating so their imports and generated headers reference `go.uber.org/mock/gomock` rather than the archived `github.com/golang/mock/gomock`. The generated mocks should look like what the new mockgen emits.

Oh and one specific thing for a particular charger type: the mock for its e-mobility interface should be generated locally inside that charger's own module instead of being imported from an external library module. Right now those charger tests depend on a mock that lives in some external module, and I want them self-contained so the mock gets generated right there in the charger's package and the tests use the local one. No more reaching out to the external module's mock for that interface.

Also update the dependency manifest (the `go.mod`) so `go.uber.org/mock` shows up as a direct dependency and the old `github.com/golang/mock` is gone. Make sure everything still builds and the tests still pass after the swap.
