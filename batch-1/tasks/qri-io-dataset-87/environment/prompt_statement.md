I'm working with a dataset library that has several core types — for commits, datasets, metadata, data structures, transforms, and visualization configs. Each of these types holds an internal path field that tracks where the data is stored. The problem is that there's currently no public way to set this path from a plain string after the object has been created. I need each of these types to have a method that accepts a string and sets the internal path appropriately. When an empty string is passed, the path should be reset to its zero value; when a non-empty string is passed, the path should be set to the key corresponding to that string. This should work consistently across all six types.
