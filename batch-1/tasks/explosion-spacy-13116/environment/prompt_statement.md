For Faroese I want a language class under `@spacy/lang/fo/` with tokenizer exceptions and punctuation rules so common abbreviations like "v.m.", "m.a.", "nr.", and the month abbreviations stay as single tokens, decimal numbers written with commas like "2,7" stay together as one token, and regular punctuation still separates cleanly off words.

After this `get_lang_class("fo")` and `get_lang_class("nn")` should both return valid language classes.
