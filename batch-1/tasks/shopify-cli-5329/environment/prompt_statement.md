I'm cleaning up the Shopify CLI theme dev server, mostly around how it does HTTP and how it surfaces errors, and I want your help. First thing, we're currently pulling `fetch` and `Response` from a third-party HTTP package and I want to drop that dependency entirely and switch to the native built-in fetch API that modern Node gives us. Please migrate everything across the theme environment utilities so nothing imports from that external HTTP lib anymore.

Second, the function that patches HTML responses coming back from the storefront renderer currently mutates the outgoing server response in place, it takes an event object and writes onto it, and I'd rather it just return a proper `Response` object instead so the data flow is cleaner and it's easier to test.

Third, the HTML rendering pipeline needs real error handling. Right now if the renderer hands back a 4xx (think account routes or app-specific routes it can't handle) the server just falls over. Instead I want it to fall back to proxying the request straight to the store, and if that proxy comes back with a status below 400 return that, otherwise return the original renderer response. If the renderer throws a network error outright, return an HTML error page with a 502 status and inject the hot-reload script so the dev sees the error and still gets live updates. Same idea for pending file upload errors in the local theme, skip rendering entirely and return an error page that lists the failed files and their error messages, again with the hot-reload script included.

Oh and last thing, I want two reusable utilities for fetch errors. One creates a structured fetch error object from either a `Response` or a thrown `Error`, and the other pulls out displayable info from that object, headline, status, status text, request ID, and URL, defaulting to a 502 Bad Gateway status when it's just a plain error. Motivation here is devs currently get silent failures or confusing behavior on redirects, auth-gated pages, and network hiccups, so I want error recovery to be predictable and always give actionable feedback.
