I'm hitting a real problem with native histograms in the querier layer of Cortex. When histogram data (both the integer and float histogram variants) gets stored in block storage and I query it back through the store gateway path, the results come out wrong. I traced it down to the batch iterator layer, in `@pkg/querier/batch`, where the query engine asks for a float histogram representation of a chunk that actually holds an integer histogram, and the iterator just doesn't handle that conversion so it hands back garbage. Modern Prometheus query engines pretty much always ask for float histograms no matter how the data was stored, so right now any native histogram data in Cortex is effectively unqueryable, which blocks folks from adopting native histograms at all.

What I want is the whole query pipeline supporting native histograms end to end. Histogram series should come back correctly when queried through store gateways, overlapping histogram series returned from multiple gateways need to be deduplicated and merged properly, and the existing resource limits (chunks per query, chunk byte limits, series limits, and data byte limits) all need to apply to histogram chunks the same way they already do for regular float sample chunks. The key fix is that when the engine requests a float histogram view of an integer histogram chunk it should get correctly converted values back.

There's also some test plumbing to sort out. The chunk generation helper needs to support generating chunks with custom labels so tests can build histogram chunks for specific label sets, and there's an obsolete, no longer used function in the ingester client compatibility layer (around `@pkg/ingester/client`) that should just be removed. Oh and the querier tests shouldn't only run against float encodings anymore, I want them running across all three chunk encoding types (regular float, native histogram, and native float histogram), with histogram-specific aggregations like summing or counting histogram data covered too, and results validated per encoding type.
