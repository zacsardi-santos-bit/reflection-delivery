I'm working on the Gleam language server and I want to add a code action that turns a pipeline expression into an equivalent regular function call. Right now if I'm using the pipe operator to chain a call there's no way to flip it back to a direct call in the editor, I have to rewrite it by hand which is tedious and easy to get wrong. So I want a "Convert to function call" refactoring option that shows up when my cursor is on or near a pipeline expression.

When I invoke it, it should rewrite the first step of the pipeline into a direct call with the piped value dropped into the right argument slot. It needs to handle all the usual forms: the common case where the piped value just becomes the first argument, bare function references with no parens, functions written with empty parens, module-qualified function references, and the trickier case where the function on the right already has all its args and returns another function so the piped value gets applied to that result. It should also handle explicit argument holes (the placeholder), whether that placeholder sits in the first position or somewhere later in the arg list.

Oh and one important detail, when there are multiple chained pipe steps only the first step should get converted, the rest of the chain stays as a pipeline. This is really just about being able to toggle between pipeline style and direct-call style fast when one reads better than the other in a given spot.
