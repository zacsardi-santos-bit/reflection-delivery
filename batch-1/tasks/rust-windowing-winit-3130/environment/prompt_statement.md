I'm cleaning up the gesture events in winit and the naming is bugging me. Right now the window event variants for pinch/magnification, double-tap smart zoom, and two-finger rotation are all named after the touchpad hardware, which is fine on desktop but feels wrong the moment I think about mobile where a touchscreen fires the exact same gestures. It ties the API to one input device and makes cross-platform gesture code confusing to write, so I want to rename these variants to describe the action the user is doing rather than the hardware that triggered it.

So the two-finger pinch/magnification event should get a generic action-focused name that just says "this is a pinch gesture" without implying touchpad-only. Same deal for the double-tap smart magnification event, rename it to reflect the gesture type, and the two-finger rotation event should be renamed to reflect the rotation action. Basically these should read as platform-agnostic so the same names work whether it's a trackpad or fingers on a screen.

Important part, don't touch the fields on any of these. The device identifier, the delta value, and the touch phase (where applicable) all stay exactly as they are, no breaking changes to the field structure. It's purely a variant rename so developers can write unified gesture handling that works the same across platforms. You'll find these defined in the event types over in `@src/event.rs` and I'd expect the renames to ripple out anywhere these variants get matched or emitted, including the platform backends.
