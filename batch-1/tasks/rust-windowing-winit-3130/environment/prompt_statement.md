I'm working on the winit windowing library and I'd like to rename some of the gesture-related window event variants to better reflect the gesture action rather than the specific hardware that triggers it. Right now the pinch/magnification event, the double-tap smart zoom event, and the rotation event all have names that reference the touchpad hardware, which makes them feel out of place when I want to extend gesture support to other platforms like mobile devices where touchscreens trigger the same gestures.

I'd like the pinch gesture event to have a more generic, action-focused name — something that conveys "this is a pinch gesture" without implying it only comes from a touchpad. Same for the double-tap gesture and the rotation gesture. The fields on these events (device ID, delta values, and touch phase) should stay the same; I just want the variant names to change so they're platform-agnostic and reflect what the user is doing, not which device they're using.
