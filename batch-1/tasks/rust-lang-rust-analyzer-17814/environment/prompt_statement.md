I'm working on rust-analyzer and I want hover to tell me about object safety when I mouse over a trait. Right now hovering a trait definition gives me the signature and docs but nothing about whether it works as a dynamic dispatch target, and I keep hitting compiler errors about traits not being object-safe only after the fact, which is annoying when the IDE could just tell me up front.

So what I want: when I hover an object-safe trait, the hover docs should say it's safe for dynamic dispatch. And when the trait isn't object-safe, the hover should say dynamic dispatch isn't supported and explain the specific reasons why, like calling out that a particular method has no receiver, or that the trait needs the implementing type to be sized, or that a method has generic type params, etc.

To make that possible the analysis layer needs a way to enumerate all the object safety violations for a given trait. The violations I need detected: the trait itself requiring the implementing type to be Sized, associated type bounds that reference the implementing type (Self), associated constants, generic associated types, and non-object-safe supertraits. Then the per-method ones, oh and these are the method-level violations: a missing receiver (static methods), generic type parameters on the method, references to the implementing type in parameter or return position, and receivers that can't actually be dispatched dynamically. One exception, methods that carry a bound requiring the implementing type to be Sized should be exempt from those method-level checks since they get skipped for dyn purposes anyway.

Basically I want to surface all the standard object safety rules directly in hover so it's obvious whether a trait can be used as a `dyn Trait` and, if not, exactly which rule it's tripping over instead of me mentally walking through the list or waiting on rustc.
