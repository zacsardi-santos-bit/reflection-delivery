I'm building out the metrics side of things and I've got snapshots recording counters plus data-distribution measurements (durations and sizes) across different users and machines, but right now there's no way to see how any of it moves over time, so I want to turn a bunch of snapshots into time series data. Each snapshot carries a start time, end time, user, hostname, and the metric values. What I need first is a builder that takes a list of snapshots and a chosen metric (a plain counter, a duration distribution, or a size distribution) and produces the series grouped by the source of the measurement, either by user-and-host together, by host alone, or everything aggregated into one combined bucket, and when I don't pass a grouping it should default to grouping by user and hostname together.

The tricky part is bucketing across time. If a snapshot sits entirely inside one time bucket its full value lands there, but when it spans multiple buckets (say something running 12:30 to 15:30 covering three hourly buckets) the value has to be split proportionally by how much of the snapshot's duration falls in each bucket, and that same proportional split needs to apply to the histogram bucket counts on distribution metrics too, not just counters.

I also want a handful of ready-made time resolutions: hourly, daily, weekly with a choice of starting Sunday or Monday, monthly, quarterly, and yearly, with daily being the default when none is given. Each resolution takes a point in time and hands back the start and end of the period that point belongs to. These have to be right at the boundaries, so the last nanosecond before a period's end still counts as the current period and not the next one, and applying the function to a period's own start should map to that same period (idempotent). Oh and if the metric name I ask for isn't present in any of the snapshots, just give me back an empty collection instead of erroring out. This is the foundation for dashboards and trend reports later, so I want the proportional math and boundary handling solid.
