I'm working on the Pulsepoint bidder adapter in our prebid server and I need to extend it to support multiple ad formats beyond just banner. Right now, any impression that isn't a banner gets rejected with an error, and bids always come back typed as banner regardless of what was actually in the impression. I need it to support banner, video, audio, and native impressions, with the bid type in the response reflecting the actual media type of the matched impression. Bids that don't match any impression, or match an impression with no recognized media type, should just be dropped silently.

I also want to remove the ad size field from the bidder extension — it's currently a required parameter but we don't need it anymore. The extension should only require the publisher ID and tag ID fields. Along with this, I want to relax the validation: missing or zero publisher IDs should not cause an error. Instead, if no valid publisher ID is found across the impressions, an empty string should be used. When selecting which publisher ID to use for the outgoing request, we should use the one from the first valid impression rather than the last one.
