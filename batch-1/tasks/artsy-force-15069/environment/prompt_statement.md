I'm working on the artist works-for-sale page in our app. Right now, when users filter artworks by medium (like paintings or sculptures), the browser tab title stays static and doesn't change to reflect their selection. I'd like to add a component that dynamically updates the page title based on whichever medium filters are currently active.

The component should show a default title when no mediums are selected, and update to include the selected mediums when filters are applied — listing them alphabetically. If two mediums are selected, they should be joined with "and"; if three or more are selected, they should be formatted as a comma-separated list with "and" before the last item. When filters are cleared, the title should fall back to the default. The component also needs to handle the case where medium filters are passed in via URL parameters at initial page load, so the title is accurate on first render too.
