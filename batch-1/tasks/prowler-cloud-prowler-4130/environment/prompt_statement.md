I'm working on adding a new security check to Prowler for AWS RDS. The check should verify whether an AWS account has configured event notifications for database security group events — specifically, both the configuration change and failure event categories need to be monitored via active subscriptions.

Currently, the RDS service layer doesn't retrieve event subscription information at all, so I need to extend it to fetch and expose that data. The event subscription objects need to capture at least the topic ARN, whether the subscription is enabled, the source type, the subscribed event categories, and the region.

The new check should evaluate each region's event subscriptions and produce findings accordingly: if an active subscription covers database security group events for all categories, it should pass; if a subscription only covers one of the two required categories, it should fail with a specific message about which category is missing; and if there are no relevant subscriptions at all, it should fail indicating both categories are not covered. The check should also respect the existing Prowler behavior of skipping findings when the scan is configured to ignore services with no active resources and no database instances are present.
