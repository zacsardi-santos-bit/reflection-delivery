I'm working on extending the Google Sheets integration in Apache Airflow. Currently, the hook can read and write cell values, but there's no way to retrieve a full spreadsheet object by its ID, list the sheet titles within a spreadsheet (with optional filtering), or programmatically create a new spreadsheet. I need those three methods added to the existing hook.

Beyond the hook, I need three new operators in a new operators module for Google Sheets. The first should create a new spreadsheet and make the resulting spreadsheet ID and URL available to downstream tasks. The second should export sheets from a Google Spreadsheet to Google Cloud Storage as CSV files — it should iterate over the sheets (optionally filtered by title), write each sheet's data to a temporary CSV file, upload it to a GCS bucket under a path constructed from the spreadsheet title and sheet range, and publish the list of destination file paths for downstream use. The third operator should go in the reverse direction: download a CSV file from GCS and upload its contents into a specified Google Spreadsheet range, defaulting to the first sheet.

I also need an example DAG module that demonstrates these operators working together, with a constant for the GCS bucket name that the system tests can reference. Finally, there should be a path constant in the test utilities pointing to the new example DAGs folder for the Google Suite providers.
