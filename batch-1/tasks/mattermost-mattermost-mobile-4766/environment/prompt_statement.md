I'm cleaning up test boilerplate in the Mattermost mobile project and it's driving me a bit nuts. Right now every test file that needs to render a component with i18n support or with a Redux store rolls its own little rendering helper from scratch, and it's the same code copy-pasted everywhere. On top of that a bunch of test files each declare their own mock for the native image picker library even though the mock setup is always identical, so if anything changes we're stuck updating a dozen copies.

What I want is one shared spot for these testing utilities. Give me three rendering helpers there: one that wraps a component with just the internationalization provider, one that wraps with just the Redux store provider, and one that wraps with both. They should have sensible defaults so callers only pass in what's actually different for their case, and then the individual test files import from this shared utility instead of defining their own local versions.

Also, the image picker mock should move into the global test setup so it applies everywhere automatically. Once that's done the individual test files shouldn't need their own copies anymore, so strip those out too. The idea is one place to change things, less drift between files, and new tests just follow the same pattern without the copy-paste ritual.
