I'd like to add support for Webnames.ru as a DNS provider in the lego ACME client. I have domains registered with Webnames and I want to be able to automate certificate issuance and renewal using DNS-01 challenges without having to manually create and delete DNS records.

The provider should be configurable via an API key environment variable. When the key is missing, the provider should fail at initialization with an informative error message. The underlying HTTP client that communicates with the Webnames API should send form-encoded POST requests with the appropriate fields to add or remove DNS TXT records. When the API returns a success indicator, the operation should complete without error; when it returns a failure indicator, the error should be surfaced to the caller.
