I want to add a new outlier detector to pyod that uses kernel-based dimensionality reduction. The idea is you project the data into a lower-dimensional space with a kernel function and then use the reconstruction error as the anomaly score, so points that can't be reconstructed well are the likely outliers. This complements the linear approaches we already have and helps folks working with non-linearly separable data where there's more complex structure to capture, like kernel PCA style projection.

It needs to behave like every other detector in the library, so fitting on training data and then scoring test data via the usual decision_function, predicting labels, estimating probabilities (with the multiple methods support, e.g. linear and unify), computing rank-based scores, and returning confidence alongside predictions and probabilities. It should also play nice with scikit-learn's clone so it survives model cloning.

Also I need an optional sampling mode since kernel methods get slow on big datasets, where only a random subset of training data fits the underlying transformation. Users should be able to give the subset size as a fraction of the training set (a positive value up to 1.0) or as an absolute count (a positive integer up to the full training set size). Invalid subset sizes should raise a clear error, so a fractional value of 0 or greater than 1, a non-positive integer, or an integer bigger than the training set size all need to blow up early with an informative message.

Oh and the number of components used in the dimensionality reduction should be configurable, plus there's an option to select only a subset of those components for the actual scoring. Negative component counts should error, and selected-component counts that exceed the total number of components or are non-positive should error too. New file should live alongside the other detectors under `@pyod/models/`.
